# Product visual brief

Bind each asset to product/SKU, color, dimensions, quantity, packaging text, logo, included accessories, source file and permitted edits. State which elements require original-pixel preservation and which background or scene can change. Do not imply source fidelity can be guaranteed by a negative prompt alone.

Specify subject, composition, background, light, palette, aspect ratio and text-safe areas. Supply exact overlay copy separately from illustrative generation. If there is no reliable product reference, label the result as concept direction rather than an accurate product rendering.

For motion specify starting asset, per-shot SKU, camera/subject movement, duration, transitions and captions. Avoid demonstrations whose mechanism, accessory or performance is unsupported by the product facts. A scene must not imply water resistance, load rating or medical benefit merely because it looks persuasive.

Pass the brief to the existing image/video production capability. Its actual-output inspection should establish variant/packaging consistency, text correctness, readable layout and requested file specifications; this brief cannot assert that inspection occurred.
