# Creative delivery

Return only requested assets: a message card, complete image copy, generation-ready brief or full storyboard. A storyboard can use: time | SKU/source | visual | exact caption | narration | proof | CTA.

Apply the shared writing method linked from the Skill root to the full storyboard, including captions, narration and implied demonstrations. Creative staging describes a proposed shot, not evidence that the product achieved a result.

When handing off to media production, include the relevant fact/asset brief: resolved product identifiers, approved copy, preservation requirements, supported effects, missing evidence, target placement/specification and acceptance criteria. Proposed shots remain proposed until actual media exists and is inspected.

If alternatives are useful, show a small set that changes the message or execution, not product facts. Include an experiment only when it answers a real uncertainty. Reuse the user's approved direction without another confirmation round.
