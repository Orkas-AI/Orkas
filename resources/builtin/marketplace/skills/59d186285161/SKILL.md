# Ecommerce Creative

Turn verified product facts into executable creative briefs. For shared message selection and revision, read `@skill/ecommerce-listing/references/source-based-writing.md` through the available `ecommerce-listing` Skill. Then resolve the placement, source assets, format and requested action for the creative route.

- For image/detail-page copy, read [visual copywriting](references/visual-copywriting.md).
- For generation-ready briefs, read [product visual prompts](references/product-visual-prompts.md).
- For hooks, scripts and shot plans, read [video storyboards](references/video-ad-storyboard.md).
- Apply [claim checks](references/creative-compliance.md) to the selected route; deliver with [output guidance](references/creative-output-templates.md).

Use the approved direction when present. If a material creative decision is unresolved, present a small concrete choice while completing independent work; do not add a mandatory approval stop to every draft. Detailed directions, prompts and storyboards are deliverables, not generated media. Hand actual production to the available media capability with the fact and asset brief; retain its existing general-purpose workflow and permissions.

This Skill requires no paid provider and invokes no generation or publication service itself.
