# Writing delivery

Return the requested finished copy first, in the requested order, language and format. Use the audience distinction in [source-based writing](source-based-writing.md) for any handoff. Composition files and reference IDs are working material, not customer copy.

For an audit, pair each material issue with a replacement and reason. For A+, give module purpose, ready copy and image brief. For a requested experiment, vary one message or structure and state the observation plan without promising conversion lift. Include only the assets and supporting detail useful to the requested decision.
