# Cross-platform product writing

## One fact base, separate channel outputs

Maintain product/variant ID, brand, material, pack count, dimensions and units, compatible use, included accessories, approved claims with sources, price/promotion conditions and permitted assets. Keep conflicting sources visible and use only resolved facts in final copy. Do not apply one SKU's attributes to its siblings.

For each requested channel identify market, language, category, listing field and source of field constraints. Write a shared factual core, then separate channel drafts; do not paste an Amazon title/bullet structure into every channel.

| Channel | Adaptation to establish from actual page or schema |
| --- | --- |
| Taobao / Tmall / JD | Item attributes, SKU labels, title and detail modules; distinguish store/service promises from product facts |
| Pinduoduo | Pack quantity, variant and conditional price; ensure the copy describes the item actually sold |
| Douyin / Kuaishou / TikTok Shop | Product-page fields versus content hooks, live scripts and creator claims; align the destination offer |
| Amazon | Marketplace and product type, parent/child content, title/bullets/description and A+ availability |
| Shopify / WooCommerce | Product/variant fields, theme sections, SEO metadata and app-specific review or FAQ modules |
| Shopee / Lazada / AliExpress | Local category attributes, variation labels, destination units/language and fulfillment conditions |
| eBay | Category item specifics, condition, variation and shipping/return fields versus description |
| Etsy | Item/variation, customization, production facts and lead time |
| Walmart | Product type, required attributes, variants and seller offer details |

This is a drafting coverage map. Exact character limits, required fields, image restrictions and eligibility are market/category/version dependent; verify only those needed for the task. Unlisted channels use the same mapping method with supplied or current official evidence. No row certifies a live connector.

## Channel composition

Use the shared [source-based writing method](source-based-writing.md) for factual wording. Channel adaptation changes layout, emphasis, search terms, voice and audience scenes. Lead with the buyer's main decision, then the relevant specifications, use, evidence and objections. Supply conservative or creative alternatives only when useful, holding the supported statements and their conditions constant. A keyword list is not measured search volume.

Design reference: [listforge-prompts](https://github.com/Dariamks/listforge-prompts) separates common, platform, locale and variant instructions. Adopt that separation, not its fixed platform limits. [Commerce merchant catalog](https://github.com/anthropics/commerce-agents/tree/main/merchant-agent/skills/catalog-listings) separates catalog evidence from copy and image briefs. No upstream code or runtime is vendored.
