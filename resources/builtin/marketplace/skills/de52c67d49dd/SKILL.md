# Ecommerce Listing

Use [source-based writing](references/source-based-writing.md) to select messages, draft and review the complete copy before handoff, including inherited drafts. This shared method covers introductions, FAQs, scripts, translation and edits; use it with the brief's subject, sources, audience and voice.

- For channel fields, add [cross-platform writing](references/cross-platform-listing.md); for Amazon modules, add [Amazon listing and A+](references/amazon-listing-and-a-plus.md). Ordinary prose keeps its requested format.
- Check relevant claims and current channel requirements with [claim and channel checks](references/listing-compliance.md).
- Deliver with [writing delivery](references/listing-output-templates.md).

Supplied materials need no external service. Keyword placement is a writing choice unless actual data establishes demand. Use `ecommerce-creative` for image directions and scripts; media generation and store writes belong to their owning capabilities.
