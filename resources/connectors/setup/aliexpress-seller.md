# aliexpress-seller

## Entry
AliExpress Open Platform → app details.

## Configure
Inspect the approved seller app with Seller Solution API access, set the supplied callback and continue through main-seller authorization. Buyer, affiliate and dropshipping-only apps are different routes.

## Credentials
Use [[field:app_key]] and [[field:app_secret]] from the seller app.

## Verify
Read merchant identity and a bounded product result. Fully managed stores and price writes are not supported verification targets.
