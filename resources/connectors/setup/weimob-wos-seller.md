# weimob-wos-seller

## Entry
Weimob Cloud product app console → overview/development configuration and Authorization Management → Authorized Stores.

## Configure
Inspect the self-owned WOS app, required abilities and authorization for the business_operation_system_id store type. New Cloud PID 1.0 is a different integration.

## Credentials
Use [[field:shop_id]], [[field:client_id]] and [[field:client_secret]]; do not substitute public_account_id.

## Verify
Read an available authorized-store resource and compare the WOS store binding.
