# youzan-seller

## Entry
Youzan Cloud → apps → self-use app overview and authorized store information.

## Configure
Inspect store binding and the required capability packages before connecting. Match the store grant to the app rather than using unrelated shop credentials.

## Credentials
Use [[field:kdt_id]], [[field:client_id]] and [[field:client_secret]]; KDT ID and grant_id refer to the same bound store here.

## Verify
Read the store identity and compare KDT ID, then a bounded product result.
