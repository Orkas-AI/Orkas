# shein-seller

## Entry
SHEIN Open Platform → Console → App Management.

## Configure
Inspect the approved self-operated/semi-managed app, required APIs and supplied callback. Continue through main-shop-account authorization; fully managed supply-chain credentials are not interchangeable.

## Credentials
Use [[field:app_id]] and [[field:app_secret]] from that app.

## Verify
Read merchant identity or warehouse/product data using an available read action. Physical-stock writes are not a verification step.
