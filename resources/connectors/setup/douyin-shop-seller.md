# douyin-shop-seller

## Entry
Douyin Shop Open Platform → App Management → App Center; use the supplied official guide to locate the console.

## Configure
Inspect the verified entity and approved self-use Merchant backend system app. Prepare missing non-sensitive application details; system documentation/software copyright and platform review are prerequisites, not automatic approvals. After API approval, inspect app Authorization Management and Seller Console → Shop → Shop Management → Service Authorization.

## Credentials
Use [[field:shop_id]], [[field:app_key]] and [[field:app_secret]] from the same authorized app/shop.

## Verify
Read shop identity and compare the authorized shop. Missing qualifications or approval requires the specific remaining material/action, not a full configuration checklist.
