# shopline

## Entry
The target myshopline.com store admin, Apps → Develop Apps.

## Configure
Inspect or prepare a private app with the exact scopes in the supplied requirements, then complete installation at the required confirmation point.

## Credentials
Use [[field:store_domain]] and the installed app Admin API [[field:access_token]], not a storefront token.

## Verify
Read store identity and a small product/inventory result. A custom domain or another SHOPLINE product is not this binding.
