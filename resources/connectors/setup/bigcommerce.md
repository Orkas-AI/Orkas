# bigcommerce

## Entry
The target store admin, Settings → Store-level API accounts.

## Configure
Inspect an existing dedicated API account or prepare a new one. Apply the permission choices in the supplied requirements; no callback is needed.

## Credentials
Map the API Path to [[field:store_hash]] and the account token to [[field:access_token]].

## Verify
Read store information and a small product list; confirm the store is the intended one.
