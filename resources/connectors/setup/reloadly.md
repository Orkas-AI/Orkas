# reloadly

## Entry
Reloadly Dashboard → API credentials; select the product matching [[field:product]].

## Configure
Locate the live credential pair for that product. Sandbox credentials and credentials for another product cannot establish the live wallet connection.

## Credentials
Use [[field:client_id]] and [[field:client_secret]] from the same live environment.

## Verify
Read an available balance or catalog resource. Never purchase airtime or gift cards merely to test the credentials.
