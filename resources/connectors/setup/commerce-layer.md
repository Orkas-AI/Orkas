# commerce-layer

## Entry
Organization Dashboard → Developers → API credentials.

## Configure
Inspect or prepare Integration credentials and their role. Use the supplied requirements for the intended read/customer-management capabilities, not restricted Sales channel credentials.

## Credentials
Use [[field:organization_slug]], [[field:client_id]] and [[field:client_secret]] from the same organization/integration.

## Verify
Read the application or a small SKU list. A read success does not establish customer-write permissions.
