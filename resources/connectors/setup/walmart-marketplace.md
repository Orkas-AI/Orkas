# walmart-marketplace

## Entry
Seller Developer Portal for the production market selected in [[field:market]].

## Configure
Locate the intended seller production credentials using the official onboarding guide. Do not use a supplier/affiliate integration or sandbox pair.

## Credentials
Use [[field:client_id]] and [[field:client_secret]] from that seller/market.

## Verify
Read an available seller/item resource and verify the market. No order or inventory mutation is needed for a connection check.
