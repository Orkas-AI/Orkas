# Xero CLI

## Entry
Start Xero through the protected connector configuration flow and its host-managed official CLI authorization.

## Configure
Use the PKCE user-authorization flow and the intended organization/tenant. The current catalog does not request a merchant-created application's secret.

## Credentials
The host owns the device-local authorization profile. Do not copy browser cookies or CLI credential files into chat.

## Verify
Discover capabilities and read a small available tenant/accounting resource. Do not create an invoice or payment to prove connectivity.
