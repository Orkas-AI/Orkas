### 당신의 자신의 내용에 대한 참조 비디오를 재생

**VideoStudio**는 당신의 자신의 제품, 스크립트 및 영상을 사용하여 바이러스성 영상의 narrative 구조, 시각적인 작풍 및 편집 속도를 재구성할 수 있습니다. 참고 비디오 파일 및 자산을 공급 : 에이전트는 후크, 정보 주문, 시각 비트를 분석하고 행동으로 전화하고 보존하고 생산하기 전에 교체하는 것을 제안합니다.

모션 그래픽 설명자, SaaS 또는 앱 데모 및 기존 영상에서 만들어진 제품 광고에 가장 적합합니다. 로컬로 저자 된 텍스트, 캡션, narration 및 클립은 별도로 개정 할 수 있습니다; AI-generated 영상으로 구운 텍스트는 그 영상을 변경해야합니다.

> " 30 초 수직 프로모션에 대한 참조로 reference.mp4을 사용하십시오. 훅을 유지, 타이포그래피 및 패싱, 내 제품 및 화면 녹화로 콘텐츠를 교체하고, 내 고장과 계획을 먼저 보여줍니다. "

비디오 파일로 시작 에이전트가 읽을 수 있습니다; 소셜 플랫폼 공유 링크 다운로드는 내장되지 않습니다. Exact 카메라 움직임, 인간 성능 및 프레임 별 일치는 보장되지 않습니다. [reference-recreation 워크플로우](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md)를 참조하십시오.

## 작업 이동 유지

하나의 작업은 좋은 시작입니다. Orkas는 계속하는 일을 위해 건축됩니다.

- **Projects** - 프로젝트의 모든 대화가 처음부터 시작되는 목표 & 규칙, 기억 및 파일, 그래서 당신은 찰상에서 결코 짧지 않습니다.
- **To-dos 및 Auto-advance** - 모든 프로젝트는 사람들 및 대리인을 위한 to-do 명부가 있습니다; 에 Auto-advance로, 팀은 그것의 자신의에 다음 품목을 선택하고 당신의 검토를 위해 완성되는 일을 가져옵니다.
- **Scheduled Automations** - 모든 작업 시간, 매일, 주간 또는 매월 실행. Orkas는 컴퓨터에 실행됩니다. v1.9에서, 각 자동화는 컴퓨터가 일어나거나 Orkas가 시작될 때 12 시간 안에 가장 최근 놓인 실행을 붙잡습니다.
- **Connectors** - Gmail, Google Calendar, Sheets 및 Drive, Notion, Slack, Shopify, Stripe 및 더 많은 것. 기본적으로 Orkas는 전송, 게시물 또는 삭제하기 전에 묻습니다.
- **Apps** - 도구와 Orkas는 데스크탑 앱 내에서 로컬 앱으로 빌드합니다. 패키지 앱에서 유료 플랜도 공개 링크로 웹 앱으로 게시 할 수 있습니다.
- **Shared project** *(packaged app)* - 팀메이트 또는 VA를 초대하고, 각 TO-DO를 사람 또는 대리인에게 줍니다.

> [! NOTE]
> 공유 프로젝트, 클라우드 동기화 및 웹 앱 게시는 패키지 응용 프로그램에서만 - 오픈 소스 빌드는 아직 지원하지 않습니다. 그들을 사용 하 여,**[다운로드Orkas제품정보macOS & Windows](https://orkas.ai/download/?source=gh-orkas&entry_point=github_readme&download=1)** (무료, 시작 500 크레딧).

음성 입력은 소스 빌드에서 작동합니다. **Orkas API Key**를 **Settings → Models**로 구성하면 작곡가 옆에 마이크를 클릭하십시오. 마이크로폰 접근 가능 오디오는 Orkas로 전송되며 주요 소유자의 Orkas 크레딧을 사용합니다. 텍스트를 다시 클릭하고 자신을 보내. 액세스가 거부되면 시스템 설정에서 마이크를 활성화합니다.

## 어떻게 작동합니까?

### 작업 라우팅

Commander는 일반 작업 자체를 처리하고 3 개의 도구를 통해 전문 작업을 위임합니다.

- **`dispatch_to`**는 지명한 대리인을 실행하고 지속적인 일을 위한 그것의 결과를 돌려보냅니다. 그것은 결과 또는 비동기적으로 실행하고 작업 종료시 Commander를 통지 할 수 있습니다.
- **`hand_off_to`**는 지명한 대리인에 남아 있는 일을 이동하고 현재 Commander 회전을 끝납니다. 대리인은 그것의 자신의 대답을 전달합니다; 선택적인 continuation는 Commander를 뒤에 더 넓은 일을 재개합니다.
- **`run_worker`**는 익명, 고립 된 하위 태스크를 실행하고 개인 결과를 반환합니다. 대화의 역사 또는 이름의 대리인의 기술을받지 않습니다.

Named 에이전트 작업 및 익명 노동자는 별도의 concurrency 컨트롤이 있습니다. [dispatch 구현](./src/main/features/group_chat/bus.ts) 및 [execution locks](./src/main/util/locks.ts)를 참조하십시오.

### Context 관리

선택된 모델의 사용 가능한 입력 용량에 대한 런타임 예산, 신속한, 도구 및 지속 가능한 실행 상태에 대한 회계. 완성된 대화는 최근 몇 가지 창을 활용합니다. 최근의 작업을 유지하면서 이전 프로세스 메시지를 집계하는 긴 활동 작업은 체크포인트를 사용합니다. File reads, file changes and command execs also have Structured record that can lived context compaction.

[context 예산](./src/core-agent/src/agent/context-budget.ts), [session 역사와 checkpoints](./src/core-agent/src/agent/session.ts) 및 [workspace 레코드](./src/core-agent/src/agent/workspace-state.ts)XZ.

### 기억과 도서관

튼튼한 노트는 사용자 선호도, 프로젝트 사실 및 각 에이전트의 재사용 가능한 지식은 별도의 범위. 이 노트는 라이브러리의 문서 인덱스와 저장된 대화 기록과 구별됩니다.

라이브러리는 패스로 문서를 추출하고 로컬 SQLite 벡터 인덱스를 저장합니다. 그것의 embedding 모형은 당신의 기계에 뛰습니다; `library` 공구는 파일, 관련 통행을 목록으로 만들 수 있고 세계적인 현재 프로젝트 도서관에서 근원 내용을 읽습니다. 초기 대화는 `chat_history`를 통해 개별적으로 검색됩니다.

이름 *[범위 메모리](./src/main/features/memory.ts), [문서 추출](./src/main/util/file_to_chunks.ts), [Library 도구](./src/main/model/core-agent/kb-tools.ts)이름 *[대화 retrieval](./src/main/model/core-agent/chat-history-tools.ts).

### 실행 제한 및 복구

Session locks and concurrency limits 경계 병렬 작업. 도구 라운드 예산, 진도 체크 포인트, 반복 호출 체크 및 단계 인식 아이들 워치 개는 런치 또는 반복 작업을 포함 하는 실행을 포함 합니다. Named 에이전트 작업은 개별적으로 추적 및 취소 할 수 있습니다; 인정 또는 할당 된 작업은 완료 된 결과로 처리되지 않습니다.

[actor 예산](./src/main/features/group_chat/actor-budgets.ts), [agent 런타임](./src/core-agent/src/agent/runner.ts) 및 [desktop 모델 어댑터](./src/main/model/core-agent/client.ts).

### 활동의 학습

배경 리뷰는 idle이 될 때 새로운 에이전트 활동을 검토하고 재사용 대기시간과 실행 제한을 수행 할 수 있습니다. 검토는 대리인의 각자 배치 (`COMPETENCE.md`), 재사용할 수 있는 방법 (`LEARNING_STRATEGIES.md`)를 업데이트할지도 모릅니다 또는 배운 기술. 리뷰는 작업 수보다 오히려 새로운 활동에 의존하며, 저장 가치가 없다는 것을 결론을 수 있습니다.

[reflection 스케줄러](./src/main/features/reflection-orchestrator.ts) 및 [review prompt](./src/core-agent/src/evolution/metacognition.ts)를 보십시오.

## 제품 정보

**ZOrkas는 무엇입니까?**
Orkas는 오픈 소스 (MIT), 로컬 첫 멀티 시약 데스크탑 응용 프로그램입니다. Commander는 토도와 좌표로 목표를 전환 16 내장 전문 에이전트 - 플러스 Claude Code, Codex, OpenCode, OpenClaw 및 Hermes-Agent - 완성 된 파일을 제공. 단일 채팅봇이 아닌 코드 프레임 워크가 아닌 호스팅 SaaS.

**나는 필요API키?**
이름 * 패키지 응용 프로그램은 내장 Orkas 모델의 500 크레딧으로 제공됩니다. 그 후, 신용을 구입, 유료 플랜을 선택하거나 자신의 공급자 키를 추가; 공급자 요금은 별도입니다.

**Is Orkas 로컬 LLM?**
이름 * Orkas는 기계에 실행하고 당신이 선택하는 모형을 부르십시오 — 붙박이 Orkas 모형, 당신의 자신의 API 열쇠, 또는 국부적으로 모형 엔드포인트. 그것은 관현 에이전트 및 도구; 그것은 자체 모델이 아닙니다.

**수 있습니다.Orkas내 문서에서 질문에 대답, 인용?**
예. 로컬 라이브러리에 PDF 및 문서를 추가하십시오. Orkas는 소스 패스에 인용과 답변을 검색 할 수 있으므로 원본 및 확인을 열 수 있습니다. 색인은 당신의 기계에 건축됩니다.

**같은 로컬 모델을 사용할 수 있습니다.Ollama또는LM Studio?**
예. **Account 설정 → 모델 → 채팅 → 모델 추가 → Custom**, **OpenAI-compatible** 또는 **Anthropic-compatible**, 기본 URL, 정확한 모델 ID 및 API 키 입력. 작업의 모델 컨트롤에서 저장된 모델을 선택하십시오.

**내 위치API키 및 데이터 저장?**
기본적으로 디스크에. 당신의 자신의 공급자 열쇠는 국부적으로 암호화되고 구름 sync에서 제외됩니다. 당신의 자신의 열쇠로, 모형은 공급자에 당신의 기계에서 똑바른 갑니다; 붙박이 Orkas 모형은 Orkas의 관리한 서비스를 사용합니다. 옵션 클라우드 동기화 및 공유 프로젝트 패키지 응용 프로그램에서 선택한 데이터를 저장 Orkas 서버. [Security 및 데이터 처리 →](https://orkas.ai/security/?source=gh-orkas)

**이름 *Orkas일 오프라인?**
소스 빌드는 로컬 모델 엔드포인트에 대해 완전히 오프라인을 실행할 수 있습니다. 패키지 앱은 로그인해야 하며, 클라우드 모델은 네트워크 연결을 필요로 합니다.

**컴퓨터가 꺼질 때 작동합니까?**
아니요 - Orkas는 컴퓨터에서 실행되므로 자동 구동 및 자동화는 컴퓨터 awake 및 Orkas 실행이 필요합니다. v1.9에서, 각 자동화는 컴퓨터가 일어나거나 Orkas가 시작될 때 12 시간 안에 가장 최근 놓인 실행을 붙잡습니다.

**앱을 구축하고 게시할 수 있나요?**
예. Orkas 내부를 실행하는 로컬 앱은 무료입니다. 웹 앱을 공개 링크에 게시하면 유료 플랜 (Lite 5, Pro 8, Max 15 apps)가 필요합니다. 웹 앱은 Orkas 내에서 모든 기능을 포함하지 않습니다.

**나는 필요Orkas계정?**
패키지 데스크톱 앱은 먼저 시작할 때 로그인해야 합니다. 이 저장소의 소스 빌드는 계정 레이어가 전혀 없습니다. — 그것은 앱으로 바로 부츠.

**수 있습니다.Orkas지도 보기Claude Code기타CLI에이전트?**
예. Orkas는 로컬 서브 프로세싱으로 5개의 외부 CLI 에이전트를 구동할 수 있습니다 — 코딩 에이전트 Claude Code, Codex 및 OpenCode, 그리고 개인 에이전트 OpenClaw 및 Hermes-Agent — 그리고 HyperFrames와 같은 온보드 오픈 소스 프로젝트, 모두 같은 채팅을 지시합니다.

**이름 *Orkas다른 것에서Claude Code / Codex / CrewAI / LangChain?**
Claude Code와 Codex는 코딩 대리인입니다 — Orkas는 그것의 팀의 일원으로 둘 다, 그래서 당신은 그들 사이에서 선택할 필요가 없습니다; CrewAI와 LangChain는 부호 첫번째 기구입니다. Orkas는 Commander가 전문 에이전트와 CLI 에이전트의 팀을 조정하는 오픈 소스 데스크톱 응용 프로그램입니다, 어떤 모델 공급자와, 데이터와 키를 로컬. [전체 비교](https://orkas.ai/compare/?source=gh-orkas)를 참조하십시오.

**어떤 플랫폼Orkas지원?**
macOS 12 + (Apple 실리콘 및 Intel) 및 Windows 10 + 패키지 설치가 있습니다. glibc 2.34+ Linux x64/arm64는 오늘 근원에서, 설치가 아직 없이 달립니다. Local Speech transcription은 Linux에서 첫 번째 발사에 준비된 핀 whisper.cpp 런타임을 통해 지원됩니다. 알파인 및 기타 musl 기반 배포가 지원되지 않습니다. 소스 부츠 스트랩은 Node 22.12 +; Python 3 및 C / C++ 빌드 도구 체인은 네이티브 npm 패키지가 호환되지 않은 사전 제작 된 바이너리가 필요하며 로컬로 재건해야합니다.
