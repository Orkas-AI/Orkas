ai 방법은 모션 그래픽 설명기, SaaS 또는 앱 데모 및 기존 영상에서 제작된 제품 광고에 가장 잘 작동합니다. 로컬 저술 문헌, 캡션, 서사지와 클립을 별도로 수정할 수 있습니다. AI 생성 영상으로 구워진 텍스트는 해당 영상을 변경해야합니다.

## 계속 진행하세요

하나의 임무는 좋은 시작입니다. Orkas는 계속되는 일에 적합합니다.

- **프로젝트** — ✓ 프로젝트의 모든 대화가 시작되는 목표와 규칙, 메모리 및 파일, 그래서 처음부터 간략하게 설명하지 않습니다.
- **과제 및 자동 진행** — 모든 프로젝트에는 사람 및 에이전트에게 해야 할 일 목록이 있습니다. 자동 진행으로 팀은 다음 항목을 스스로 선택하고 완료된 작업을 검토에 가져옵니다.
- **계획된 자동화** — Orkas는 컴퓨터에서 실행됩니다. 1.9 버전부터, 모든 자동화는 컴퓨터가 깨어남 또는 Orkas가 시작되면 12 시간 ai내에 가장 최근에 놓친 실행을 잡습니다.
- **연결기** — Gmail, Google 캘린더, 시트 및 드라이브, 노션, Slack, Shopify, 스트라이프 등 많은 것들이 있습니다. 기본적으로 Orkas는 어떤 것을 전송하거나 게시하거나 삭제하기 전에 묻습니다.
- **앱** — 도구에 대해 설명하고 Orkas는 데스크톱 앱 내부에서 로컬 앱으로 만들 수 있습니다. 패키지 앱에서는 유료 계획 또한 공개 링크를 가진 웹 앱으로 게시 할 수 있습니다.
- **공유 프로젝트** — *(복합 앱)*팀 동료나 VA를 초대하고 각 작업을 한 사람 또는 에이전트에 맡겨라.

> [!NOTE]
> 공유 프로젝트, 클라우드 동기화 및 웹 앱 게시물은 패키지 응용 프로그램에서만 있습니다. 오픈소스 빌드는 아직 지원하지 않습니다.**[macOS & Windows에 Orkas를 다운로드](https://orkas.ai/download/?source=gh-orkas&entry_point=github_readme&download=1)** (자료로 시작해서 500점으로)

## 왜 Orkas가

- **계획하고, 위임하고, 나머지는 하는 Commander** — 그것은 목표를 분해하고, 적절한 요인, 기술, 연결기 및 도구를 선택하고, 어떤 전문가가 더 적합하지 않은 상태에서 분석, 글쓰기, 연구 및 파일 작업을 직접 처리합니다.
- **지역적-처음 설계** —  대화, 파일, 지식 기반 및 사용자 지정 에ai전트는 기본적으로 디스크에 남아 있습니다. 클라우드 동기화는 패키지 앱에서 선택적입니다. 자신의 키로 모델 호출은 기계에서 공급자에게 직접 이동합니다. 내장된 Orkas 모델은 Orkas의 관리 된 모델 서비스를 통해 실행됩니다.
- **어떤 모델이든, 언제든** — Commander과 내장된 에이전트는 하나의 모델 설정: 내장된 Orkas 모델, 귀하의 개인 공급업체는 또는 지역 엔드포인트. 외부 CLI 에이전트는 자신의 모델 설정을 유지합니다.
- **더 나은 요원** — 각 에이전트는 개인 기술과 기억을 유지합니다. 배경 리뷰는 앱이 비활성일 때 새로운 활동을 조사하고 자기 평가, 재사용 가능한 방법 및 학습된 기술을 정비 할 수 있습니다.
- **오픈소스, 블랙박스 없습니다** — MIT에 라이선스 받았어 Orkas와 모든 에이전트와 실력이 무엇인지 정확히 읽어봐

## 어떻게 작동하는지

### 작업 라우팅

Commander은 직접 일반 작업을 처리하고 전문적인 작업을 세 가지 도구로 위임합니다.

- **`dispatch_to`** — ai 기기는 그 결과를 계속하기 위해 이름을 붙인 에이전트를 실행하고 결과를 반환합니다.
- **`hand_off_to`** — 남은 작업을 명명된 에ai전트에 전송하고 현재의 Commander 회전을 끝낸다. 에이전트는 자신의 답변을 전달한다. 선택적 연속은 지휘관이 더 넓은 작업을 다시 시작할 수 있게 한다.
- **`run_worker`** — 익명적이고 고립된 하위 작업을 실행하고 개인 결과를 반환합니다. 대화 역사 또는 이름 지어진 에이전트의 기술을 수신하지 않습니다.

이름 붙여진 에이전트 작업과 익명의 노동자들은 별도의 동시 제어 기능을 가지고 있습니다.[파견의 실행](./src/main/features/group_chat/bus.ts)그리고[실행 잠금](./src/main/util/locks.ts).

### 컨텍스트 관리

실행 시간 예산의 맥락은 선택된 모델의 사용 가능한 입력 용량, 명령어, 도구 및 지속적인 실행 시간 상태를 계산하는 것과 비교합니다. 완료 대화는 제한된 최근 역사 창을 사용합니다. 긴 활성 작업은 ai전 프로세스 메시지를 응축하는 점들을 사용하여 최근의 작업을 유지합니다. 파일 읽기, 파일 변경 및 명령 실행 또한 컨텍스트 컴팩션을 생존할 수있는 구조화된 기록을 가지고 있습니다.

보시다시피[컨텍스트 예산](./src/core-agent/src/agent/context-budget.ts), [세션 역사와 체크포인트](./src/core-agent/src/agent/session.ts)그리고[작업 공간 기록](./src/core-agent/src/agent/workspace-state.ts).

### 기억과 도서관

내구성 메모는 사용자 선호도, 프로젝트 사실 및 각 에이전트의 재사용 가능한 지식을 별도의 범위에서 보관합니다. 이 메모는 도서관 문서 지표와 저장된 대화 역사와는 다릅니다.

라이브러리는 문서를 문장으로 추출하고 로컬 SQLite 벡터 인덱스를 저장합니다.`library`이 도구는 파일들을 목록화하고 관련 문서를 검색하고 글로벌 또는 현재 프로젝트 라이브러리에서 소스 콘텐츠를 읽을 수 있습니다.`chat_history`.

### 집행 제한 및 회수

세션 잠금 및 동시 제한은 병렬 작업을 묶어줍니다. 도구 라운드 예산, 진전 점검점, 반복 호출 검사 및 단계 인식의 비활성 감시견은 작업을 중단하거나 반복하는 실행을 억제하는 데 도움ai됩니다. 이름 붙인 에이전트 작업은 개별적으로 추적 및 취소 할 수 있습니다. 허용되거나 줄을 잇는 작업은 완료된 결과로 취급되지 않습니다.

## FAQ

**Orkas란 무엇인가?**
Orkas는 오픈소스 (MIT) 로컬-첫 번째 멀티 에이전트 데스크톱 앱입니다. 그 커맨더는 당신의 목표를 토즈로 변환하고 16 개의 내장 전문 에이전트를 조정합니다.

**API key가 필요해?**
아뇨. 패키지 앱은 내장된 Orkas 모델에 500점으로 제공됩니다. 그 후, 크레딧을 구입하거나 유료 계획을 선택하거나 자신의 공급자 키를 추가하십시오. 공급자 수수료는 별개입니다.

**Orkas는 현지 법학대학원인가요?**
Orkas는 컴퓨터에서 실행되고, 여러분이 선택한 모델들을 ἀ 내장된 Orkas 모델, 자신의 API key 또는 로컬 모델 엔드포인트로 호출합니다.

**Orkas는 문서를 인용해서 답변할 수 있을까요?**
네. 로컬 라이브러리에 PDF 파일과 문서를 추가하세요. Orkas는 검색하여 소스 페이지를 인용하여 답변할 수 있습니다. 그래서 원본을 열고 확인할 수 있습니다. 지수는 컴퓨터에 구축됩니다.

**올라마나 LM 스튜디오 같은 로컬 모델들을 사용할 수 있나요?**
그래, 열어**계정 설정 → 모델 → 채팅 → 모델 추가 → 사용자 정의**, 선택** OpenAI 호환성**또는** 인тропо- 호환성**, 그리고 기본 URL, 정확한 모델 ID 및 API key를 입력합니다. 작업의 모델 컨트롤에서 저장된 모델을 선택하십시오.

**내 API key와 데이터가 어디에 저장되어 있습니까?**
기본 디스크에 저장됩니다. 귀하의 자체 제공자 키는 로컬 암호화되어 클라우드 동기화에서 제외됩니다. 귀하의 자신의 키와 함께 모델 호출은 컴퓨터에서 직접 제공자에게 ai동합니다. 내장 Orkas 모델은 Orkas의 관리 서비스를 사용합니다. 옵션 클라우드 동기화가 및 공유 프로젝트는 패키지 앱에서 선택된 데이터를 저장합니다.[보안 및 데이터 처리](https://orkas.ai/security/?source=gh-orkas)

**Orkas는 오프라인에서 작동합니까?**
소스 빌드는 로컬 모델 엔드포인트에 완전히 오프라인으로 실행될 수 있습니다. 패키지 앱은 로그인해야 하며 클라우드 모델에는 네트워크 연결ai 필요합니다.

**컴퓨터가 꺼져 있으면 계속 작동합니까?**
◎ Orkas (Orkas) 는 컴퓨터에서 실행되기 때문에 자동개발과 자동화에는 컴퓨터가 깨어 있고 Orkas가 실행되어야 합니다. 1.9 버전부터, 모든 자동화는 컴퓨터가 깨어 있거나 Orkas가 시작되면 12 시간 이내에 가장 최근에 놓친 실행을 잡습니다.

**앱을 만들고 출판할 수 있나요?**
예. Orkas 내에서 실행되는 로컬 앱은 무료입니다. 공개 링크에 웹 앱을 게시하려면 유료 플랜 (Lite 5, Pro 8, Max 15 앱) ai 필요합니다. 그리고 출판된 웹 앱은 Orkas 내부에서 사용할 수있는 모든 기능을 포함하지 않습니다.

**Orkas 계좌가 필요해?**
패키지 데스크톱 앱은 처음 시작했을 때 로그인하도록 요청합니다. ai 저장소에서 생성된 소스에는 전혀 계정 계층이 없습니다.

**Orkas는 Claude Code와 다른 CLI 요원을 운전할 수 있나요?**
Orkas는 5개의 외부 CLI 에이전트를 로컬 하위 프로세스로 켜고 있습니다. 코드링 에이전트 Claude Code, Codex 및 OpenCode, 개인 에이전트 OpenClaw와 Hermes-Agent 그리고 HyperFrames즈 같은 오픈소스 프로젝트에서 모두 같은 채팅에서 지시됩니다.

**Orkas는 Claude Code/Codex/크루아ai/랑체인에서 어떻게 다르다?**
Claude Code와 Codex는 코딩 에ai전트입니다. Orkas는 팀의 멤버로 모두 실행하므로 둘 중 하나를 선택할 필요가 없습니다. 크루아이와 랭체인은 코드-첫 프레임워크입니다. 오락사는 오픈소스 데스크톱 앱으로, 커맨더가 전문 에이전트들과 CLI 에이전트들의 팀을 어떤 모델 공급자와 조정하고 데이터와 키를 로컬로 보관합니다.[전체 비교](https://orkas.ai/compare/?source=gh-orkas).

**Orkas가 지원하는 플랫폼은 무엇일까요?**
macOS 12+ (Apple Silicon, Intel) 및 Windows 10+에는 패키지 설치가 있습니다. glibc 2.34+ Linux x64/arm64는 현재 소스에서 실행되며 아직 설치가 없습니다. 로컬 음성 변환은 첫 출시에 준비된 핀 된 whisper.cpp 런타임을 통해 리눅스에서 지원됩니다. 알파인 및 기타 근육 기반 배포가 지원되지 않습니다. 소스 부트스트랩은 Node 22.12+가 필요합니다. Python 3 및 C / C++ 빌드 체인 도구는 네ai티브 npm 패키지가 호환 가능한 사전 구축 바이너리를 가지고 있지 않은 경우에만 필요하며 로컬로 재건해야합니다.

**Orkas는 무료이고 오픈소스인가요?**
예 ️ 앱은 MIT 라ai선스 및 사용 무료입니다. 패키지 응용 프로그램은 내장된 Orkas 모델에 대한 500 크레딧을 포함합니다. 월 11.99 달러 / 달부터 지불 된 계획은 월별 크레딧, 클라우드 동기화, 더 많은 공유 프로젝트 및 응용 프로그램 출판을 추가합니다. 자신의 키와 함께, 모델 사용은 공급자가 청구합니다. Orkas는 표시를 추가하지 않습니다.[가격](https://orkas.ai/pricing/?source=gh-orkas)
