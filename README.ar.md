# Orkas

**فريق مفتوح المصدر من وكلاء الذكاء الاصطناعي على حاسوبك، يحوّل أهدافك إلى عمل منجز ويواصل دفعه إلى الأمام.**

يُعدّ Orkas تطبيقًا مفتوح المصدر (MIT) متعدد الوكلاء لسطح المكتب يعطي الأولوية للعمل المحلي، وهو مساعد ذكاء اصطناعي يعمل كفريق. أخبر **القائد** (Commander) بما تحتاج إليه: فهو ينجز كثيرًا من المهام بنفسه، أما في الأعمال الأكبر فيخطط للخطوات ويستعين بوكلاء متخصصين إلى جانب وكلاء البرمجة والوكلاء الشخصيين الذين تستخدمهم بالفعل — **Claude Code وCodex وOpenCode وOpenClaw وHermes-Agent** — ليعملوا عليها معًا.

صُمّم Orkas ليواصل دفع المشروع إلى الأمام، لا ليجيب عن طلب واحد فحسب. يضمّ **المشروع** الهدف والقواعد والذاكرة والملفات، فتستأنف كل محادثة جديدة من حيث توقفت سابقتها. وتوزّع **المهام المطلوبة** العمل بين الأشخاص والوكلاء، ويتيح **التقدم التلقائي** للفريق أن يتولى المهمة المطلوبة التالية من تلقاء نفسه، وتكرر **الأتمتة المجدولة** الأعمال الروتينية كل ساعة أو يوم أو أسبوع أو شهر. تبقى جميع بياناتك على حاسوبك، ويعود إليك العمل المنجز لمراجعته، لذا يمكنك أن تأتمن Orkas على الأعمال المستمرة لنشاطك التجاري.

### أعد إنشاء فيديو مرجعي بمحتواك الخاص

**وكيل VideoStudio** قادر على إعادة إنشاء البنية السردية لفيديو واسع الانتشار وأسلوبه البصري وإيقاع مونتاجه باستخدام منتجك ونصّك ولقطاتك الخاصة. قدّم ملف الفيديو المرجعي وموادك: يحلّل الوكيل الافتتاحية الجاذبة وترتيب المعلومات والإيقاع البصري والدعوة إلى اتخاذ إجراء، ثم يقترح ما يجب الإبقاء عليه وما يجب استبداله قبل بدء الإنتاج.

تعمل هذه الطريقة على أفضل وجه مع مقاطع الشرح بالرسوم المتحركة، والعروض التوضيحية لخدمات SaaS أو التطبيقات، وإعلانات المنتجات المبنية من لقطاتك الموجودة. يمكن تعديل النصوص والتسميات التوضيحية والتعليق الصوتي والمقاطع المُعدّة محليًا كلٌّ على حدة؛ أما النص المدمج في لقطات مولَّدة بالذكاء الاصطناعي فيتطلب تغييره تغيير تلك اللقطات نفسها.

> «استخدم reference.mp4 مرجعًا لفيديو ترويجي عمودي مدته 30 ثانية. حافظ على افتتاحيته وأسلوب خطوطه وإيقاعه، واستبدل المحتوى بمنتجي وتسجيلات شاشتي، واعرض عليّ التحليل والخطة أولًا.»

ابدأ بملف فيديو يستطيع الوكيل قراءته؛ فتنزيل المقاطع من روابط المشاركة في منصات التواصل الاجتماعي غير مدمج. ولا تُضمن مطابقة حركات الكاميرا بدقة، ولا أداء الأشخاص، ولا التطابق إطارًا بإطار. راجع [سير عمل إعادة الإنشاء من فيديو مرجعي](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

## حافظ على استمرار العمل

المهمة الواحدة بداية جيدة، لكن Orkas مصمَّم للعمل الذي يستمر.

- **المشاريع** — أهداف وقواعد وذاكرة وملفات تنطلق منها كل محادثة في المشروع، فلا تضطر أبدًا إلى شرح كل شيء من الصفر.
- **المهام المطلوبة والتقدم التلقائي** — لكل مشروع قائمة مهام مطلوبة للأشخاص والوكلاء؛ وعند تفعيل التقدم التلقائي يتولى الفريق البند التالي من تلقاء نفسه ويعيد إليك العمل المنجز لمراجعته.
- **الأتمتة المجدولة** — شغّل أي مهمة كل ساعة أو يوم أو أسبوع أو شهر. يعمل Orkas على حاسوبك. بدءًا من الإصدار v1.9، تستدرك كل عملية أتمتة آخر تشغيل فاتها خلال 12 ساعة، وذلك عند استيقاظ الحاسوب أو بدء تشغيل Orkas.
- **الموصّلات** — Gmail وGoogle Calendar وSheets وDrive وNotion وSlack وShopify وStripe وغيرها الكثير. ويطلب Orkas إذنك افتراضيًا قبل أن يرسل أي شيء أو ينشره أو يحذفه.
- **التطبيقات** — صِف أداة وسيبنيها Orkas تطبيقًا محليًا داخل تطبيق سطح المكتب. وفي التطبيق الجاهز، تتيح الخطط المدفوعة أيضًا نشرها تطبيقَ ويب برابط عام.
- **المشاريع المشتركة** *(في التطبيق الجاهز)* — ادعُ زميلًا في الفريق أو مساعدًا افتراضيًا، وأسند كل مهمة مطلوبة إلى شخص أو وكيل.

## البدء السريع

هل تفضّل مثبّتًا جاهزًا بدلًا من ذلك؟ راجع قسم [التنزيل](#التنزيل) أعلاه. للتشغيل من المصدر، وهو حاليًا طريقة تشغيل Orkas على Linux:

**المتطلبات**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 أو arm64. احتفظ بـ Python 3 وسلسلة أدوات بناء C/C++ متاحة تحسبًا للحالة النادرة التي يلزم فيها بناء وحدة أصلية من المصدر كحل احتياطي.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

يتطلب التشغيل من المصدر على Linux وجود glibc 2.34+. ولا تُدعم توزيعة Alpine وغيرها من التوزيعات المبنية على musl. وعند التشغيل الأول من المصدر، تنزّل ميزة تفريغ الكلام المحلي بيئة تشغيل whisper.cpp الأصلية للمنصة المستهدفة والنموذج متعدد اللغات وتتحقق منهما.

عند التشغيل الأول، يثبّت `run.sh` / `run.cmd` شجرة تبعيات npm المقفلة، ويجهّز الموارد المثبّتة الإصدار: Python وuv وNode ونموذج التضمين (~95 MB) وOfficeCLI وFFmpeg وwhisper.cpp ونموذج الكلام متعدد اللغات. ثم يتحقق بدء التشغيل على Linux، قبل فتح التطبيق، من الوحدات الأصلية للمنصة وبيئة تشغيل Whisper وفق واجهة ABI الخاصة بـ Electron. وتُثبَّت حزم Python الخاصة بـ OCR وببعض المهارات في بيئات محلية معزولة عند استخدام تلك الميزات لأول مرة. ويُنشئ التشغيل الأول مساحة عمل ضمن `~/.orkas/` (macOS / Linux) أو `<smallest non-system drive>:\.orkas\` (Windows). ثم افتح **الإعدادات ← مزوّدو الذكاء الاصطناعي** لإضافة مفتاح API أو OAuth.

عند ظهور أخطاء في التبعيات الأصلية: استخدم Node.js 24 LTS (الحد الأدنى 22.12.0)، ثم شغّل
`npm run native:repair` من نسخة العمل هذه. يستعيد هذا الأمر الحزم الاختيارية،
ويصلح SQLite لـ Electron، ويجهّز Node المضمَّن لمعالجة الصور بشكل معزول،
ويتحقق من SQL وsqlite-vec وsharp قبل الإعلان عن النجاح.
استخدم `npm run native:check` لإجراء فحص دون تثبيت.
راجع [سكربت التحقق من التبعيات الأصلية](./scripts/verify-native-dependencies.cjs) لمعرفة الفحوص التي يجريها.

## كيف يعمل

### توجيه المهام

يتولى القائد العمل العام بنفسه، ويفوّض الأعمال المتخصصة عبر ثلاث أدوات:

- تشغّل الأداة **`dispatch_to`** وكيلًا مسمّى وتعيد نتيجته لمواصلة العمل. ويمكنها انتظار النتيجة، أو العمل بشكل غير متزامن وإشعار القائد عند انتهاء المهمة.
- تنقل الأداة **`hand_off_to`** العمل المتبقي إلى وكيل مسمّى وتُنهي دور القائد الحالي. ويقدّم الوكيل ردّه بنفسه، ويتيح استكمال اختياري للقائد أن يستأنف مهمة أوسع بعد ذلك.
- تشغّل الأداة **`run_worker`** مهمة فرعية مجهولة الهوية ومعزولة، وتعيد نتيجة خاصة. ولا تتلقى هذه المهمة سجل المحادثة ولا مهارات أي وكيل مسمّى.

لمهام الوكلاء المسمّين وللعمّال مجهولي الهوية ضوابط تزامن منفصلة. راجع [تنفيذ التوزيع](./src/main/features/group_chat/bus.ts) و[أقفال التنفيذ](./src/main/util/locks.ts).

### إدارة السياق

تخصّص بيئة التشغيل ميزانية السياق وفقًا لسعة الإدخال القابلة للاستخدام في النموذج المحدد، مع مراعاة الموجّهات والأدوات وحالة التشغيل الدائمة. ويستخدم الحوار المكتمل نافذة محدودة من السجل الحديث؛ أما المهام النشطة الطويلة فتستخدم نقاط تحقق لتكثيف رسائل العملية السابقة مع الإبقاء على العمل الحديث. كما تحظى قراءات الملفات وتغييراتها وعمليات تنفيذ الأوامر بسجلات منظّمة يمكن أن تبقى بعد ضغط السياق.

راجع [ميزانيات السياق](./src/core-agent/src/agent/context-budget.ts) و[سجل الجلسة ونقاط التحقق](./src/core-agent/src/agent/session.ts) و[سجلات مساحة العمل](./src/core-agent/src/agent/workspace-state.ts).

### الذاكرة والمكتبة

تحفظ الملاحظات الدائمة تفضيلات المستخدم وحقائق المشروع والمعرفة القابلة لإعادة الاستخدام لكل وكيل في نطاقات منفصلة. وهذه الملاحظات مستقلة عن فهرس مستندات المكتبة وعن سجل المحادثات المخزَّن.

تستخرج المكتبة المستندات في صورة مقاطع نصية وتخزّن فهرسًا متجهيًا محليًا في SQLite. ويعمل نموذج التضمين الخاص بها على جهازك؛ ويمكن للأداة `library` سرد الملفات والبحث في المقاطع ذات الصلة وقراءة المحتوى المصدري من المكتبة العامة أو مكتبة المشروع الحالي. أما المحادثات السابقة فتُسترجع بشكل منفصل عبر `chat_history`.

راجع [الذاكرة حسب النطاق](./src/main/features/memory.ts) و[استخراج المستندات](./src/main/util/file_to_chunks.ts) و[أدوات المكتبة](./src/main/model/core-agent/kb-tools.ts) و[استرجاع المحادثات](./src/main/model/core-agent/chat-history-tools.ts).

### حدود التنفيذ والتعافي

تضع أقفال الجلسات وحدود التزامن سقفًا للعمل المتوازي. وتساعد ميزانيات جولات الأدوات ونقاط التحقق من التقدم وفحوص الاستدعاءات المتكررة ومراقبات الخمول المراعية لمرحلة التنفيذ على احتواء عمليات التشغيل التي تتعثر أو تكرر العمل. ويمكن تتبع مهام الوكلاء المسمّين وإلغاؤها كلٌّ على حدة؛ ولا تُعامَل المهمة المقبولة أو الموضوعة في قائمة الانتظار على أنها نتيجة مكتملة.

راجع [ميزانيات الجهات الفاعلة](./src/main/features/group_chat/actor-budgets.ts) و[بيئة تشغيل الوكلاء](./src/core-agent/src/agent/runner.ts) و[محوّل النماذج لتطبيق سطح المكتب](./src/main/model/core-agent/client.ts).

### التعلم من النشاط

تفحص المراجعات الخلفية نشاط الوكلاء الجديد حين يكون التطبيق خاملًا، مع مراعاة فترات التهدئة وحدود التنفيذ. وقد تحدّث المراجعة التقييم الذاتي للوكيل (`COMPETENCE.md`) أو أساليبه القابلة لإعادة الاستخدام (`LEARNING_STRATEGIES.md`) أو مهاراته المكتسبة. وتعتمد المراجعات على النشاط الجديد لا على عدد المهام، وقد تخلص إلى أنه لا يوجد ما يستحق الحفظ.

راجع [مجدول التأمل](./src/main/features/reflection-orchestrator.ts) و[موجّه المراجعة](./src/core-agent/src/evolution/metacognition.ts).

## الأسئلة الشائعة

**ما هو Orkas؟**
يُعدّ Orkas تطبيقًا مفتوح المصدر (MIT) متعدد الوكلاء لسطح المكتب يعطي الأولوية للعمل المحلي. يحوّل قائده هدفك إلى مهام مطلوبة، وينسّق 16 وكيلًا متخصصًا مدمجًا — إلى جانب Claude Code وCodex وOpenCode وOpenClaw وHermes-Agent — لتسليم ملفات منجزة. وهو ليس روبوت محادثة واحدًا، ولا إطار عمل برمجيًا، ولا خدمة SaaS مستضافة.

**هل أحتاج إلى مفتاح API؟**
لا. يأتي التطبيق الجاهز مع 500 رصيد لنموذج Orkas المدمج. وبعد ذلك يمكنك شراء رصيد، أو اختيار خطة مدفوعة، أو إضافة مفاتيح مزوّدك الخاصة؛ وتُحتسب رسوم المزوّد بشكل منفصل.

**هل Orkas نموذج LLM محلي؟**
لا. يعمل Orkas على جهازك ويستدعي النماذج التي تختارها: نموذج Orkas المدمج، أو مفاتيح API الخاصة بك، أو نقطة نهاية لنموذج محلي. فهو ينسّق الوكلاء والأدوات، وليس نموذجًا بحد ذاته.

**هل يستطيع Orkas الإجابة عن الأسئلة من مستنداتي مع ذكر المصادر؟**
نعم. أضف ملفات PDF والمستندات إلى مكتبتك المحلية؛ ويمكن لـ Orkas البحث فيها والإجابة مع استشهادات تحيل إلى المقاطع المصدرية، لتتمكن من فتح الأصل والتحقق منه. ويُبنى الفهرس على جهازك.

**هل يمكنني استخدام نماذج محلية مثل Ollama أو LM Studio؟**
نعم. افتح **إعدادات الحساب ← النماذج ← المحادثة ← إضافة نموذج ← مخصص**، واختر **متوافق مع OpenAI** أو **متوافق مع Anthropic**، ثم أدخل عنوان URL الأساسي ومعرّف النموذج الدقيق ومفتاح API. بعدها اختر النموذج المحفوظ من أداة اختيار النموذج في المهمة.

**أين تُخزَّن مفاتيح API وبياناتي؟**
على قرصك افتراضيًا. تُشفَّر مفاتيح مزوّدك الخاصة محليًا وتُستثنى من المزامنة السحابية. وعند استخدام مفاتيحك الخاصة، تنتقل طلبات النماذج مباشرة من جهازك إلى المزوّد؛ أما نموذج Orkas المدمج فيستخدم الخدمة المُدارة من Orkas. وتخزّن المزامنة السحابية الاختيارية والمشاريع المشتركة في التطبيق الجاهز البيانات المحددة على خوادم Orkas. [الأمان والتعامل مع البيانات ←](https://orkas.ai/security/?source=gh-orkas)

**هل يعمل Orkas دون اتصال بالإنترنت؟**
يمكن لنسخة المصدر أن تعمل دون اتصال بالكامل مع نقطة نهاية لنموذج محلي. أما التطبيق الجاهز فيحتاج إلى تسجيل الدخول، وتحتاج النماذج السحابية إلى اتصال بالشبكة.

**هل يواصل العمل عندما يكون حاسوبي مطفأً؟**
لا — يعمل Orkas على حاسوبك، لذا يحتاج التقدم التلقائي والأتمتة إلى أن يكون الحاسوب مستيقظًا وOrkas قيد التشغيل. بدءًا من الإصدار v1.9، تستدرك كل عملية أتمتة آخر تشغيل فاتها خلال 12 ساعة، وذلك عند استيقاظ الحاسوب أو بدء تشغيل Orkas.

**هل يمكنني بناء التطبيقات ونشرها؟**
نعم. التطبيقات المحلية التي تعمل داخل Orkas مجانية. أما نشر تطبيق ويب برابط عام فيتطلب خطة مدفوعة (5 تطبيقات في Lite، و8 في Pro، و15 في Max)، ولا تتضمن تطبيقات الويب المنشورة كل القدرات المتاحة داخل Orkas.

**هل أحتاج إلى حساب Orkas؟**
يطلب منك تطبيق سطح المكتب الجاهز تسجيل الدخول عند تشغيله لأول مرة. أما نسخة المصدر في هذا المستودع فلا تحتوي على طبقة حسابات على الإطلاق، إذ تنقلك مباشرة إلى التطبيق.

**هل يستطيع Orkas التحكم في Claude Code وغيره من وكلاء CLI؟**
نعم. يستطيع Orkas التحكم في خمسة وكلاء CLI خارجيين كعمليات فرعية محلية — وكلاء البرمجة Claude Code وCodex وOpenCode، إضافة إلى الوكيلين الشخصيين OpenClaw وHermes-Agent — ودمج مشاريع مفتوحة المصدر مثل HyperFrames، وكل ذلك بتوجيه من المحادثة نفسها.

**ما الفرق بين Orkas وكلٍّ من Claude Code / Codex / CrewAI / LangChain؟**
يُعدّ Claude Code وCodex وكيلَي برمجة، ويشغّل Orkas كليهما كعضوين في فريقه، فلا تضطر إلى الاختيار بينهما؛ أما CrewAI وLangChain فهما إطارا عمل يركّزان على الشيفرة. وOrkas تطبيق مفتوح المصدر لسطح المكتب ينسّق فيه القائد فريقًا من الوكلاء المتخصصين ووكلاء CLI الخاصين بك، مع أي مزوّد نماذج، ويُبقي البيانات والمفاتيح محلية. راجع [المقارنات الكاملة](https://orkas.ai/compare/?source=gh-orkas).

**ما المنصات التي يدعمها Orkas؟**
تتوفر مثبّتات جاهزة لـ macOS 12+ (Apple Silicon وIntel) وWindows 10+. أما Linux x64/arm64 مع glibc 2.34+ فيعمل اليوم من المصدر، ولا يتوفر له مثبّت بعد. ويُدعم تفريغ الكلام المحلي على Linux عبر بيئة تشغيل whisper.cpp المثبّتة الإصدار التي تُجهَّز عند التشغيل الأول. ولا تُدعم Alpine وغيرها من التوزيعات المبنية على musl. ويحتاج التمهيد من المصدر إلى Node 22.12+؛ أما Python 3 وسلسلة أدوات بناء C/C++ فلا تلزم إلا عندما لا تتوفر لحزمة npm أصلية نسخة ثنائية متوافقة مسبقة البناء، ويجب إعادة بنائها محليًا.
