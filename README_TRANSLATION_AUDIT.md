## 修改后人工复核

### 可进入发布流程

- **简体中文**：语义基准。
- **英文**：已移除相对中文的增译和版本漂移；建议做一次英文编辑润色后发布。
- **繁体中文**：未再发现旧报告中的 `musl`→“肌肉”、FAQ→“檔案”等严重误译；适合进入台湾/香港用语复核。

### 仍需重点母语审校

以下问题属于修改后的残余风险，不是结构损坏：

- **日语**：仍有类似“ローカルファースト設計”周边句法生硬、助词和标点不自然的问题；部分技术说明呈逐词翻译感。
- **韩语**：存在“요인/대리인”等 agent 术语选择不稳定、敬语和句尾风格不统一。
- **泰语**：仍有外来词、技术词和部分非泰文字形混入，个别句子不符合自然泰语语序。
- **土耳其语**：异常重复已消除，但仍有 “Tasarım gereği yerel öncelikli” 周边搭配和格变化不自然。
- **越南语**：可理解，但 `agent`、`local-first`、`model endpoint` 等术语译法仍偏直译。
- **阿拉伯语**：版本号与数字已恢复，仍有冠词、性数一致和产品名转写不稳定。
- **西班牙语/法语/德语/意大利语/葡萄牙语/俄语/印尼语**：整体可理解，仍存在品牌名被普通名词化、英语技术词混用、句法机械和地区用语未完全区分的问题。

## 发布建议与优先级

1. **P0：日语、韩语、泰语、土耳其语、越南语、阿拉伯语**——必须由对应母语编辑逐句审校。
2. **P1：德语、西班牙语、西语拉美、法语、意大利语、葡萄牙语、俄语、印尼语**——至少完成产品术语表统一和母语抽检。
3. **P2：英文、繁体中文**——做编辑润色及地区用语确认。
4. 母语审校完成后再次运行链接、标题、代码块、数字和语言导航检查，再决定发布。
