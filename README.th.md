# Orkas

**ทีมเอเจนต์ AI โอเพนซอร์สบนเดสก์ท็อปของคุณ — เปลี่ยนเป้าหมายของคุณให้เป็นงานที่เสร็จสมบูรณ์ และผลักดันงานให้เดินหน้าต่อไป**

Orkas คือแอปเดสก์ท็อปแบบหลายเอเจนต์ที่เป็นโอเพนซอร์ส (MIT) และให้ความสำคัญกับการทำงานภายในเครื่อง — ผู้ช่วย AI ที่ทำงานเป็นทีม บอก **ผู้บัญชาการ** (Commander) ว่าคุณต้องการอะไร ผู้บัญชาการจะทำงานหลายอย่างให้เสร็จได้เอง และสำหรับงานที่ใหญ่ขึ้น จะวางแผนขั้นตอนแล้วดึงเอเจนต์ผู้เชี่ยวชาญเข้ามาร่วมกับเอเจนต์เขียนโค้ดและเอเจนต์ส่วนตัวที่คุณใช้อยู่แล้ว — **Claude Code, Codex, OpenCode, OpenClaw และ Hermes-Agent** — เพื่อทำงานนั้นร่วมกัน

Orkas สร้างมาเพื่อให้โปรเจกต์เดินหน้าต่อไปได้เรื่อย ๆ ไม่ใช่แค่ตอบพรอมต์ครั้งเดียว **โปรเจกต์** จะเก็บเป้าหมาย กฎ หน่วยความจำ และไฟล์ไว้ ทุกบทสนทนาใหม่จึงสานต่อจากจุดที่บทสนทนาก่อนหน้าค้างไว้ **สิ่งที่ต้องทำ** แบ่งงานระหว่างคนกับเอเจนต์ **เดินหน้าต่ออัตโนมัติ** ช่วยให้ทีมหยิบสิ่งที่ต้องทำรายการถัดไปมาทำได้เอง และ **งานอัตโนมัติตามกำหนดเวลา** จะทำงานประจำซ้ำทุกชั่วโมง ทุกวัน ทุกสัปดาห์ หรือทุกเดือน ข้อมูลทั้งหมดของคุณอยู่ในคอมพิวเตอร์ของคุณ และงานที่เสร็จแล้วจะถูกส่งกลับมาให้คุณตรวจทาน — คุณจึงไว้วางใจให้ Orkas ดูแลงานต่อเนื่องของธุรกิจได้

## สิ่งที่ทีมส่งมอบให้

- **วิดีโอ เสียงบรรยาย และรูปภาพ** — [VideoStudio](https://github.com/Orkas-AI/Orkas-VideoStudio), VoiceStudio, ImageStudio
- **รายงานการวิจัย การตรวจสอบ SEO และการวิเคราะห์ตลาด** — DeepResearcher, SeoGeoAgent, StockAnalyser
- **โพสต์ บทความ จดหมายข่าว และสไลด์นำเสนอ** — ContentWriter, PptMaker
- **เว็บไซต์ UI และโค้ด** — UIDesigner, ProductDeveloper
- **ไฟล์ Word, Excel, PowerPoint และ PDF** — OfficeWorker
- **งานอีคอมเมิร์ซ** — การวิจัยสินค้า การลงรายการสินค้า การวิเคราะห์รีวิว การวิเคราะห์ยอดขาย และการปรับเปลี่ยนแคตตาล็อก โดยเอเจนต์อีคอมเมิร์ซห้าตัว
- **งานซับซ้อนที่ต้องใช้หลายเอเจนต์** — ผู้บัญชาการจะแบ่งงาน ส่งแต่ละส่วนให้เอเจนต์ที่เหมาะสม แล้วรวมผลลัพธ์เข้าด้วยกัน เช่น งานวิจัยตลาดที่ต่อยอดเป็นรายงาน สไลด์นำเสนอ และวิดีโอเปิดตัว

### สร้างวิดีโอใหม่ตามวิดีโอต้นแบบด้วยเนื้อหาของคุณเอง

**VideoStudio** สามารถสร้างโครงเรื่อง สไตล์ภาพ และจังหวะการตัดต่อของวิดีโอไวรัลขึ้นใหม่ โดยใช้สินค้า สคริปต์ และฟุตเทจของคุณเอง เพียงส่งไฟล์วิดีโอต้นแบบและไฟล์ของคุณมา เอเจนต์จะวิเคราะห์ฮุกเปิดคลิป ลำดับการเล่าข้อมูล จังหวะภาพ และคำกระตุ้นให้ลงมือทำ จากนั้นเสนอว่าส่วนใดควรคงไว้และส่วนใดควรแทนที่ก่อนเริ่มผลิต

วิธีนี้เหมาะที่สุดกับวิดีโออธิบายแบบโมชันกราฟิก เดโม SaaS หรือแอป และโฆษณาสินค้าที่ตัดต่อจากฟุตเทจที่คุณมีอยู่แล้ว ข้อความ คำบรรยายใต้ภาพ เสียงบรรยาย และคลิปที่สร้างภายในเครื่องสามารถแก้ไขแยกกันได้ ส่วนข้อความที่ฝังอยู่ในฟุตเทจที่สร้างด้วย AI ต้องแก้ด้วยการเปลี่ยนฟุตเทจนั้น

> "ใช้ reference.mp4 เป็นต้นแบบ ทำวิดีโอโปรโมตแนวตั้งยาว 30 วินาที คงฮุก ฟอนต์ และจังหวะของคลิปไว้ เปลี่ยนเนื้อหาเป็นสินค้าและคลิปบันทึกหน้าจอของฉัน แล้วขอดูผลการวิเคราะห์กับแผนงานก่อน"

เริ่มจากไฟล์วิดีโอที่เอเจนต์อ่านได้ เพราะยังไม่มีฟีเจอร์ดาวน์โหลดจากลิงก์แชร์ของแพลตฟอร์มโซเชียลในตัว ไม่รับประกันการเคลื่อนกล้องที่ตรงเป๊ะ การแสดงของคน หรือการจับคู่ทีละเฟรม ดู[ขั้นตอนการสร้างวิดีโอใหม่ตามต้นแบบ](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md)

## ทำให้งานเดินหน้าต่อไป

งานชิ้นเดียวเป็นจุดเริ่มต้นที่ดี Orkas สร้างมาเพื่องานที่ดำเนินต่อไปเรื่อย ๆ

- **โปรเจกต์** — เป้าหมายและกฎ หน่วยความจำ และไฟล์ ที่ทุกบทสนทนาในโปรเจกต์ใช้เป็นจุดตั้งต้น คุณจึงไม่ต้องอธิบายใหม่ตั้งแต่ต้นอีก
- **สิ่งที่ต้องทำและเดินหน้าต่ออัตโนมัติ** — ทุกโปรเจกต์มีรายการสิ่งที่ต้องทำสำหรับคนและเอเจนต์ เมื่อเปิดการเดินหน้าต่ออัตโนมัติ ทีมจะหยิบรายการถัดไปมาทำเองและส่งงานที่เสร็จแล้วกลับมาให้คุณตรวจทาน
- **งานอัตโนมัติตามกำหนดเวลา** — รันงานใดก็ได้ทุกชั่วโมง ทุกวัน ทุกสัปดาห์ หรือทุกเดือน Orkas ทำงานบนคอมพิวเตอร์ของคุณ ตั้งแต่ v1.9 เป็นต้นไป เมื่อคอมพิวเตอร์ตื่นจากโหมดสลีปหรือเมื่อ Orkas เริ่มทำงาน งานอัตโนมัติแต่ละรายการจะรันชดเชยรอบล่าสุดที่พลาดไปภายใน 12 ชั่วโมง
- **ตัวเชื่อมต่อ** — Gmail, Google Calendar, Sheets และ Drive, Notion, Slack, Shopify, Stripe และอื่น ๆ อีกมาก โดยค่าเริ่มต้น Orkas จะถามคุณก่อนส่ง โพสต์ หรือลบสิ่งใดก็ตาม
- **แอป** — อธิบายเครื่องมือที่ต้องการ แล้ว Orkas จะสร้างให้เป็นแอปภายในเครื่องที่อยู่ในแอปเดสก์ท็อป ในแอปฉบับติดตั้ง ผู้ใช้แผนแบบชำระเงินยังเผยแพร่แอปนั้นเป็นเว็บแอปพร้อมลิงก์สาธารณะได้ด้วย
- **โปรเจกต์ที่แชร์** *(แอปฉบับติดตั้ง)* — เชิญเพื่อนร่วมทีมหรือผู้ช่วยเสมือน (VA) และมอบหมายสิ่งที่ต้องทำแต่ละรายการให้คนหรือเอเจนต์

- **ใช้โมเดลใดก็ได้ เปลี่ยนได้ทุกเมื่อ** — ผู้บัญชาการและเอเจนต์ในตัวใช้การตั้งค่าโมเดลชุดเดียวกัน: โมเดล Orkas ในตัว ผู้ให้บริการของคุณเอง หรือเอนด์พอยต์ภายในเครื่อง ส่วนเอเจนต์ CLI ภายนอกยังคงใช้การตั้งค่าโมเดลของตัวเอง
- **เอเจนต์ที่เก่งขึ้นเรื่อย ๆ** — เอเจนต์แต่ละตัวมีทักษะและหน่วยความจำส่วนตัว การทบทวนเบื้องหลังจะตรวจดูกิจกรรมใหม่ขณะที่แอปว่าง และสามารถปรับปรุงการประเมินตนเอง วิธีการที่นำกลับมาใช้ซ้ำได้ และทักษะที่เรียนรู้มา
- **โอเพนซอร์ส ไม่มีกล่องดำ** — ใช้สัญญาอนุญาต MIT อ่านได้เลยว่า Orkas รวมถึงเอเจนต์และทักษะแต่ละตัวทำอะไรบ้าง

## เริ่มต้นอย่างรวดเร็ว

ต้องการตัวติดตั้งแบบแพ็กเกจแทนใช่ไหม? ดูหัวข้อ[ดาวน์โหลด](#ดาวน์โหลด) ด้านบน หากต้องการรันจากซอร์สโค้ด — ซึ่งปัจจุบันเป็นวิธีรัน Orkas บน Linux:

**ข้อกำหนด**: Node 22.12+ · macOS / Windows 10+ / Linux x64 หรือ arm64 ที่ใช้ glibc 2.34+ ควรเตรียม Python 3 และชุดเครื่องมือบิลด์ C/C++ ไว้ด้วย สำหรับกรณีสำรองที่พบได้ไม่บ่อย ซึ่งต้องบิลด์โมดูลเนทีฟจากซอร์สโค้ด

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

การรันจากซอร์สโค้ดบน Linux ต้องใช้ glibc 2.34+ ไม่รองรับ Alpine และดิสทริบิวชันอื่นที่ใช้ musl ฟีเจอร์ถอดเสียงพูดภายในเครื่องจะดาวน์โหลดและตรวจสอบรันไทม์ whisper.cpp แบบเนทีฟสำหรับแพลตฟอร์มเป้าหมาย พร้อมโมเดลหลายภาษา ในการเปิดใช้งานจากซอร์สโค้ดครั้งแรก

`run.sh` / `run.cmd` จะติดตั้งแพ็กเกจ npm ทั้งชุดตามเวอร์ชันที่ล็อกไว้ และเตรียมทรัพยากรตามเวอร์ชันที่กำหนดไว้ ได้แก่ Python, uv, Node, โมเดลเอ็มเบดดิง (~95 MB), OfficeCLI, FFmpeg, whisper.cpp และโมเดลเสียงพูดหลายภาษา ในการเปิดครั้งแรก จากนั้นในขั้นตอนเริ่มระบบบน Linux แอปจะตรวจสอบโมดูลเนทีฟของแพลตฟอร์มและรันไทม์ Whisper ภายใต้ ABI ของ Electron ก่อนเปิดแอป แพ็กเกจ Python สำหรับ OCR และสำหรับทักษะเฉพาะบางตัวจะติดตั้งลงในสภาพแวดล้อมภายในเครื่องที่แยกออกจากกัน เมื่อมีการใช้ฟีเจอร์เหล่านั้นเป็นครั้งแรก การเปิดครั้งแรกจะสร้างพื้นที่ทำงานที่ `~/.orkas/` (macOS / Linux) หรือ `<smallest non-system drive>:\.orkas\` (Windows) จากนั้นเปิด **การตั้งค่า → ผู้ให้บริการ AI** เพื่อเพิ่มคีย์ API หรือ OAuth

หากพบข้อผิดพลาดของแพ็กเกจเนทีฟ: ให้ใช้ Node.js 24 LTS (ขั้นต่ำ 22.12.0) แล้วรัน
`npm run native:repair` ในโฟลเดอร์ซอร์สโค้ดนี้ คำสั่งนี้จะกู้คืนแพ็กเกจเสริม
ซ่อม SQLite สำหรับ Electron เตรียม Node ที่มาพร้อมแอปสำหรับการประมวลผลภาพแบบแยกส่วน
และตรวจสอบ SQL, sqlite-vec และ sharp ก่อนจะแจ้งว่าสำเร็จ
ใช้ `npm run native:check` เพื่อตรวจสอบอย่างเดียวโดยไม่ติดตั้ง
ดูรายการสิ่งที่ตรวจสอบได้ใน[สคริปต์ตรวจสอบแพ็กเกจเนทีฟ](./scripts/verify-native-dependencies.cjs)

## หลักการทำงาน

### การกำหนดเส้นทางงาน

ผู้บัญชาการจัดการงานทั่วไปเอง และมอบหมายงานเฉพาะทางผ่านเครื่องมือสามตัว:

- **`dispatch_to`** รันเอเจนต์ที่ระบุชื่อและส่งผลลัพธ์กลับมาเพื่อทำงานต่อ โดยจะรอผลลัพธ์ หรือรันแบบอะซิงโครนัสแล้วแจ้งผู้บัญชาการเมื่องานเสร็จก็ได้
- **`hand_off_to`** โอนงานที่เหลือให้เอเจนต์ที่ระบุชื่อ และจบรอบการทำงานปัจจุบันของผู้บัญชาการ เอเจนต์นั้นจะตอบกลับเอง และหากเลือกใช้การทำงานต่อ ผู้บัญชาการจะกลับมาทำงานภาพรวมที่ใหญ่กว่าต่อในภายหลังได้
- **`run_worker`** รันงานย่อยแบบไม่ระบุชื่อที่แยกออกจากส่วนอื่น และส่งผลลัพธ์ส่วนตัวกลับมา งานย่อยนี้จะไม่ได้รับประวัติบทสนทนาหรือทักษะของเอเจนต์ที่มีชื่อ

งานของเอเจนต์ที่มีชื่อและเวิร์กเกอร์แบบไม่ระบุชื่อมีการควบคุมการทำงานพร้อมกันแยกกัน ดู[โค้ดส่วนการส่งงาน](./src/main/features/group_chat/bus.ts) และ[ล็อกการประมวลผล](./src/main/util/locks.ts)

### การจัดการบริบท

รันไทม์จะจัดสรรงบบริบทตามความจุอินพุตที่ใช้ได้จริงของโมเดลที่เลือก โดยคำนึงถึงพรอมต์ เครื่องมือ และสถานะรันไทม์ที่คงอยู่ บทสนทนาที่จบแล้วใช้หน้าต่างประวัติล่าสุดแบบจำกัดขนาด ส่วนงานที่ทำงานอยู่เป็นเวลานานจะใช้จุดบันทึกเพื่อย่อข้อความระหว่างทางก่อนหน้า โดยยังเก็บงานล่าสุดไว้ การอ่านไฟล์ การแก้ไขไฟล์ และการรันคำสั่งยังมีบันทึกแบบมีโครงสร้างที่คงอยู่ได้แม้มีการบีบอัดบริบท

### หน่วยความจำและคลังข้อมูล

บันทึกถาวรจะเก็บความชอบของผู้ใช้ ข้อเท็จจริงของโปรเจกต์ และความรู้ที่นำกลับมาใช้ได้ของเอเจนต์แต่ละตัวแยกตามขอบเขต บันทึกเหล่านี้แยกจากดัชนีเอกสารของคลังข้อมูลและประวัติบทสนทนาที่จัดเก็บไว้

## คำถามที่พบบ่อย

**Orkas คืออะไร?**
Orkas คือแอปเดสก์ท็อปแบบหลายเอเจนต์ที่เป็นโอเพนซอร์ส (MIT) และให้ความสำคัญกับการทำงานภายในเครื่อง ผู้บัญชาการของ Orkas จะเปลี่ยนเป้าหมายของคุณให้เป็นสิ่งที่ต้องทำ และประสานงานเอเจนต์ผู้เชี่ยวชาญในตัว 16 ตัว — รวมถึง Claude Code, Codex, OpenCode, OpenClaw และ Hermes-Agent — เพื่อส่งมอบไฟล์ที่เสร็จสมบูรณ์ ไม่ใช่แชตบอตตัวเดียว ไม่ใช่เฟรมเวิร์กสำหรับเขียนโค้ด และไม่ใช่ SaaS ที่โฮสต์บนคลาวด์

**จำเป็นต้องมีคีย์ API หรือไม่?**
ไม่จำเป็น แอปฉบับติดตั้งมาพร้อม 500 เครดิตสำหรับโมเดล Orkas ในตัว หลังจากนั้นคุณสามารถซื้อเครดิต เลือกแผนแบบชำระเงิน หรือเพิ่มคีย์ผู้ให้บริการของคุณเองได้ โดยค่าบริการของผู้ให้บริการจะคิดแยกต่างหาก

**Orkas เป็น LLM ที่รันภายในเครื่องหรือไม่?**
ไม่ใช่ Orkas ทำงานบนเครื่องของคุณและเรียกใช้โมเดลที่คุณเลือก — โมเดล Orkas ในตัว คีย์ API ของคุณเอง หรือเอนด์พอยต์โมเดลภายในเครื่อง Orkas ทำหน้าที่ประสานงานเอเจนต์และเครื่องมือ ตัว Orkas เองไม่ใช่โมเดล

**Orkas ตอบคำถามจากเอกสารของฉันพร้อมการอ้างอิงได้ไหม?**
ได้ เพิ่ม PDF และเอกสารลงในคลังข้อมูลภายในเครื่องของคุณ แล้ว Orkas จะค้นหาและตอบพร้อมการอ้างอิงไปยังข้อความต้นฉบับ คุณจึงเปิดต้นฉบับขึ้นมาตรวจสอบได้ ดัชนีสร้างขึ้นบนเครื่องของคุณ

**ใช้โมเดลภายในเครื่องอย่าง Ollama หรือ LM Studio ได้ไหม?**
ได้ เปิด **การตั้งค่าบัญชี → โมเดล → แชต → เพิ่มโมเดล → กำหนดเอง** เลือก **เข้ากันได้กับ OpenAI** หรือ **เข้ากันได้กับ Anthropic** แล้วกรอก URL พื้นฐาน ID โมเดลที่ตรงตัว และคีย์ API จากนั้นเลือกโมเดลที่บันทึกไว้จากตัวเลือกโมเดลของงาน

**คีย์ API และข้อมูลของฉันเก็บไว้ที่ไหน?**
เก็บไว้บนดิสก์ของคุณโดยค่าเริ่มต้น คีย์ผู้ให้บริการของคุณเองจะถูกเข้ารหัสภายในเครื่องและไม่รวมอยู่ในการซิงค์คลาวด์ หากใช้คีย์ของคุณเอง การเรียกโมเดลจะส่งตรงจากเครื่องของคุณไปยังผู้ให้บริการ ส่วนโมเดล Orkas ในตัวจะใช้บริการที่ Orkas ดูแลจัดการ การซิงค์คลาวด์ (ไม่บังคับ) และโปรเจกต์ที่แชร์ในแอปฉบับติดตั้งจะจัดเก็บข้อมูลที่เลือกไว้บนเซิร์ฟเวอร์ของ Orkas [ความปลอดภัยและการจัดการข้อมูล →](https://orkas.ai/security/?source=gh-orkas)

**Orkas ใช้งานแบบออฟไลน์ได้ไหม?**
เวอร์ชันที่รันจากซอร์สโค้ดทำงานแบบออฟไลน์ได้ทั้งหมดเมื่อใช้กับเอนด์พอยต์โมเดลภายในเครื่อง แอปฉบับติดตั้งต้องลงชื่อเข้าใช้ และโมเดลบนคลาวด์ต้องใช้การเชื่อมต่อเครือข่าย

**Orkas ยังทำงานต่อได้ไหมเมื่อปิดคอมพิวเตอร์?**
ไม่ได้ — Orkas ทำงานบนคอมพิวเตอร์ของคุณ ดังนั้นการเดินหน้าต่ออัตโนมัติและงานอัตโนมัติจึงต้องให้คอมพิวเตอร์เปิดอยู่ ไม่อยู่ในโหมดสลีป และ Orkas กำลังทำงาน ตั้งแต่ v1.9 เป็นต้นไป เมื่อคอมพิวเตอร์ตื่นจากโหมดสลีปหรือเมื่อ Orkas เริ่มทำงาน งานอัตโนมัติแต่ละรายการจะรันชดเชยรอบล่าสุดที่พลาดไปภายใน 12 ชั่วโมง

**สร้างและเผยแพร่แอปได้ไหม?**
ได้ แอปภายในเครื่องที่ทำงานใน Orkas ใช้ได้ฟรี การเผยแพร่เว็บแอปผ่านลิงก์สาธารณะต้องใช้แผนแบบชำระเงิน (Lite 5, Pro 8, Max 15 แอป) และเว็บแอปที่เผยแพร่แล้วจะไม่มีความสามารถครบทุกอย่างที่มีใน Orkas

**ต้องมีบัญชี Orkas หรือไม่?**
แอปเดสก์ท็อปฉบับติดตั้งจะขอให้คุณลงชื่อเข้าใช้เมื่อเปิดใช้งานครั้งแรก เวอร์ชันที่รันจากซอร์สโค้ดในรีโพนี้ไม่มีระบบบัญชีเลย — เปิดขึ้นมาก็เข้าสู่แอปได้ทันที

**Orkas สั่งงาน Claude Code และเอเจนต์ CLI อื่น ๆ ได้ไหม?**
ได้ Orkas สามารถสั่งงานเอเจนต์ CLI ภายนอกห้าตัวในรูปแบบโปรเซสย่อยภายในเครื่อง — เอเจนต์เขียนโค้ด Claude Code, Codex และ OpenCode รวมถึงเอเจนต์ส่วนตัว OpenClaw และ Hermes-Agent — และนำโปรเจกต์โอเพนซอร์สอย่าง HyperFrames เข้ามาใช้ได้ด้วย ทั้งหมดสั่งงานได้จากแชตเดียวกัน

**Orkas ต่างจาก Claude Code / Codex / CrewAI / LangChain อย่างไร?**
Claude Code และ Codex เป็นเอเจนต์เขียนโค้ด — Orkas รันทั้งสองตัวในฐานะสมาชิกของทีม คุณจึงไม่ต้องเลือกระหว่างสองตัวนี้ ส่วน CrewAI และ LangChain เป็นเฟรมเวิร์กที่เน้นการเขียนโค้ดเป็นหลัก Orkas เป็นแอปเดสก์ท็อปโอเพนซอร์สที่มีผู้บัญชาการคอยประสานงานทีมเอเจนต์ผู้เชี่ยวชาญและเอเจนต์ CLI ของคุณ ใช้กับผู้ให้บริการโมเดลใดก็ได้ และเก็บข้อมูลกับคีย์ไว้ภายในเครื่อง ดู[การเปรียบเทียบทั้งหมด](https://orkas.ai/compare/?source=gh-orkas)

**Orkas รองรับแพลตฟอร์มใดบ้าง?**
macOS 12+ (Apple Silicon และ Intel) และ Windows 10+ มีตัวติดตั้งแบบแพ็กเกจ ส่วน Linux x64/arm64 ที่ใช้ glibc 2.34+ ปัจจุบันรันได้จากซอร์สโค้ดและยังไม่มีตัวติดตั้ง ฟีเจอร์ถอดเสียงพูดภายในเครื่องรองรับบน Linux ผ่านรันไทม์ whisper.cpp ตามเวอร์ชันที่กำหนดไว้ ซึ่งจะเตรียมให้ในการเปิดครั้งแรก ไม่รองรับ Alpine และดิสทริบิวชันอื่นที่ใช้ musl ขั้นตอนเตรียมระบบเพื่อรันจากซอร์สโค้ดต้องใช้ Node 22.12+ ส่วน Python 3 และชุดเครื่องมือบิลด์ C/C++ จำเป็นเฉพาะเมื่อแพ็กเกจ npm แบบเนทีฟไม่มีไบนารีสำเร็จรูปที่เข้ากันได้ และต้องบิลด์ใหม่ภายในเครื่อง
