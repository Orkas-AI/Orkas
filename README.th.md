# Orkas

**ทีมโอเพนซอร์สของAIตัว แทน ที่ อยู่ ใน สภาพ แวด ล้อม ของ คุณ ทํา ให้ เป้า หมาย ของ คุณ เปลี่ยน ไป เป็น งาน ที่ ทํา เสร็จ แล้ว และ ทํา งาน นั้น ต่อ ไป.**

Orkasเป็นโอเพนซอร์ส(MIT)โปรแกรมเดสก์ทอปแบบหลายเอฟเฟ็คต์ รุ่นแรก ๆ ของท้องถิ่นAIผู้ช่วยที่ทํางานเป็นทีม บอก**Commander**สิ่ง ที่ คุณ ต้องการ: มัน ทํา งาน หลาย อย่าง ได้ สําเร็จ ด้วย ตัว ของ มัน เอง และ สําหรับ งาน ที่ ใหญ่ กว่า มัน วาง แผน ขั้น ตอน และ นํา ตัว แทน ที่ เชี่ยวชาญ เข้า มา พร้อม กับ การ เขียน รหัส และ ตัว แทน ส่วน ตัว ที่ คุณ ใช้ อยู่ แล้ว —**Claude Code, Codex, OpenCode, OpenClawถึงHermes-Agent**-เพื่อร่วมมือกัน

Orkasถูกสร้างขึ้นเพื่อให้โครงการเคลื่อนไหว ไม่ใช่แค่ตอบทันที A**โครงการ**เก็บเป้าหมาย กฎ ความทรงจํา และไฟล์ไว้ ดังนั้นทุกการสนทนาใหม่ๆ จะหยิบเอาว่าอันสุดท้ายที่เหลืออยู่ที่ไหน**สิ่งที่จะทํา**แบ่งงานระหว่างคนกับเจ้าหน้าที่**แก้ไขโครงการหลัก...**ให้ทีมจัดการต่อเอง**กําหนดการอัตโนมัติ**ทํา งาน ซ้ํา ทุก วัน ทุก สัปดาห์ หรือ ทุก เดือน. ข้อมูล ทั้ง หมด ของ คุณ อยู่ ใน คอมพิวเตอร์ และ งาน ที่ ทํา เสร็จ แล้ว ก็ กลับ มา ทบทวน — คุณ จึง ไว้ ใจ ได้Orkasกับงานของคุณ

## สิ่งที่ทีมส่ง

- **วิดีโอ เสียง และภาพต่าง ๆ** — VideoStudio, VoiceStudio, ImageStudio

- **โพสต์, บทความ, จดหมาย ข่าว และ ระเบียง เลื่อน** — ContentWriter, PptMaker
- **website, UI และรหัส** — UIDesigner, ProductDeveloper
- **Word, Excel, PowerPoint และPDFแฟ้ม** — OfficeWorker
- **การทํางานของ E-commerce**การวิจัยผลิตภัณฑ์ รายการ วิเคราะห์ วิเคราะห์ การวิเคราะห์ยอดขาย และแคตตาล็อก

### สร้างวิดีโออ้างอิงใหม่ด้วยเนื้อหาของคุณเอง

**VideoStudio**สามารถสร้างโครงสร้างการเล่าเรื่องของไวรัส รูปแบบการมองเห็นและการแก้ไขได้ โดยใช้ผลิตภัณฑ์ สคริปต์และวิดีโอของคุณเอง จัดหาไฟล์วิดีโอและทรัพย์สินของคุณ: ตัวแทนวิเคราะห์ตะขอ, คําสั่งข้อมูล, การเต้นและโทรไปยังการกระทํา

อันนี้ใช้อธิบายแบบเคลื่อนไหวได้ดีที่สุดSaaSหรือแอพเดโมส์ และโฆษณาสินค้า สร้างจากภาพวิดีโอของคุณ ข้อความที่เขียนในท้องถิ่น, คําบรรยาย, การตัดต่อและตัดส่วนต่าง ๆ สามารถแก้ไขได้ ข้อความที่อบลงในเทป AI-genered ต้องมีการเปลี่ยนแปลงภาพที่

> " ใช้อ้างอิง. mp4 เพื่ออ้างอิงการโฆษณาในแนวตั้ง 30 วินาที เก็บตะขอ, การพิมพ์และเดินเลื่อน, แทนเนื้อหาด้วยผลิตภัณฑ์และบันทึกหน้าจอของฉันและแสดงให้ฉัน

เริ่มด้วยแฟ้มวีดิทัศน์ที่ตัวแทนสามารถอ่านได้; การดาวน์โหลดร่วมกันแบบสังคมแบบ Partiform ไม่ได้ถูกสร้างมา การเคลื่อนที่ของกล้อง, การดําเนินงานของมนุษย์ และการจับคู่เฟรมต่อเฟรม ไม่ได้รับการรับประกัน ดู[การเติมข้อมูล](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

## ทําต่อไป

ภารกิจหนึ่งคือการเริ่มต้นที่ดี Orkas ถูกสร้างขึ้นเพื่องานที่ดําเนินต่อไป

- **โครงการ**การ พูด คุย กัน ทุก อย่าง ใน โครงการ เริ่ม จาก เป้า หมาย และ กฎ ต่าง ๆ ดัง นั้น คุณ จึง ไม่ เคย พูด สั้น ๆ ตั้ง แต่ ต้น.
- **สิ่งที่จะทําและรุ่นอัตโนมัติ**— ทุกโครงการมีรายการทําสําหรับคนและตัวแทน; โดยมี Auto-advance เปิดใช้งาน ทีมเลือกรายการถัดไปในตัวเองและนํางานเสร็จสิ้นสําหรับทบทวนของคุณ
- **กําหนดการอัตโนมัติ**ใช้ งาน ทุก วัน ทุก สัปดาห์ หรือ ประจํา เดือน.Orkasเปิดคอมพิวเตอร์ของคุณ จาก v1.9 แต่ละอัตโนมัติจับ พลาดล่าสุดทํางานภายใน 12 ชั่วโมงเมื่อคอมพิวเตอร์ตื่นหรือOrkasเริ่มได้
- **ตัวเชื่อมต่อ** — Gmail, Google Calendar, SheetsถึงDrive, Notion, Slack, Shopify, Stripeและมากกว่านั้น โดยปริยายแล้วOrkasถามก่อนที่จะส่ง โพสต์หรือลบอะไร
- **แอป**-อธิบายเครื่องมือและOrkasสร้างเป็นโปรแกรมภายในพื้นที่ทํางาน ในแอพแพ็คเกจนี้ แผนจ่ายเงินยังสามารถเผยแพร่มันในฐานะเว็บแอพที่มีลิงก์สาธารณะ
- **โครงการที่ใช้ร่วมกัน** *(แอพพลิเคชันที่บรรจุแพกเกจ)* — เชิญ เพื่อน ร่วม ทีม หรือ VA และ ให้ แต่ ละ คน ทํา กับ คน หนึ่ง หรือ ผู้ แทน.

- **ภายในระบบแรกโดยออกแบบ**การ สนทนา, แฟ้ม ข้อมูล, พื้น ฐาน ความ รู้ และ ตัว แทน ที่ ได้ รับ การ แต่ง ตั้ง จะ คง อยู่ บนดิสก์ ของ คุณ เป็น ปกติ. กลุ่มเมฆปรับเป็นตัวเลือกเพิ่มเติมในแอพแพ็คเกจ ด้วยกุญแจของคุณเองโทรรุ่นไปตรงจากเครื่องของคุณไปยังผู้ให้บริการ; สร้างภายในOrkasรุ่นวิ่งผ่านOrkasจัดการบริการโมเดล
- **โมเดลใด ๆ สลับเวลาใด ๆ**-Commanderและตัวแทนที่สร้างขึ้นร่วมกันการตั้งค่าหนึ่ง : สร้างภายในOrkasโมเดล ผู้ให้บริการของคุณเอง หรือจุดปลายท้องถิ่น ภายนอกCLIเจ้าหน้าที่เก็บรูปแบบไว้
- **เจ้าหน้าที่ที่ดีขึ้น**-ตัวแทนแต่ละคนเก็บทักษะและความทรงจําส่วนตัวไว้ การทบทวนประวัติจะตรวจสอบกิจกรรมใหม่ๆ เมื่อโปรแกรมว่างงาน และสามารถปรับโครงสร้างตัวเอง
- **เปิดแหล่ง, ไม่มีกล่องดํา** — MITใบอนุญาติ อ่านว่าอะไรOrkasและตัวแทนและทักษะทุกคนทํา

> ○ ถ้าOrkasมีประโยชน์กับคุณมาก ดาวช่วยคนหาโครงการได้มากขึ้น

## เริ่มทํางานอย่างรวดเร็ว

ต้องการตัวติดตั้งแพกเกจแทนไหม? ดู[ดาวน์โหลด](#download)ข้างบน เพื่อ หนี จาก แหล่ง ที่ มา ซึ่ง ปัจจุบัน เป็น วิธี วิ่งOrkasบนLinux:

**เงื่อนไข**: Node 22.12+ · macOS / Windows10+ / glibc 2.34+Linuxx64 หรือแขน 64 เก็บไว้Python3 และเครื่อง C/C+ ก่อสร้างเครื่องราชอิสริยาภรณ์ ที่มีอยู่สําหรับแหล่งย่อยของแหล่งย่อยที่ผิดปกติ

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

Linuxแหล่งที่มาการทํางานต้องการ glibc 2.34+. ยังไม่รองรับการแจกจ่ายแบบมัลติมีเดียและมัลติมีเดียอื่น ๆ โปรแกรมดาวน์โหลดคําสั่งภาษาท้องถิ่น และตรวจความถูกต้องของเป้าหมายwhisper.cppเวลาและรูปแบบหลายภาษา ระหว่างการเปิดตัวแหล่งแรก

`run.sh` / `run.cmd`ติดตั้งต้นไม้ที่เชื่อมต่อ npm ที่ถูกล็อคและเตรียมตรึงPythonอูฟNodeโมเดลการฝัง(~95 MB), OfficeCLI, FFmpeg, whisper.cpp(เสียง) และเสียงพูดหลายภาษา ต้นแบบในการเปิดตัวครั้งแรกLinuxเริ่มการทํางานแล้วตรวจสอบโมดูลแพลตฟอร์มและเวลากระซิบภายใต้ElectronABI ก่อนจะเปิดแอพ OCR และตัวระบุทักษะPythonจะติดตั้งแพกเกจไว้ในสภาพแวดล้อมท้องถิ่นที่อยู่ห่างไกล เมื่อใช้คุณสมบัติดังกล่าวเป็นครั้งแรก การเปิดตัวครั้งแรกสร้างพื้นที่การทํางานภายใต้`~/.orkas/` (macOS / Linux)หรือ`<smallest non-system drive>:\.orkas\` (Windows)แล้วเปิด**ตั้งค่าต่าง ๆAIผู้จัดทํา**เพิ่มAPIกุญแจหรือOAuth.

การติดต่อแบบท้องถิ่นผิดพลาด: ใช้Node.js 24 LTS(ต่ําสุด 22.12.0)แล้ววิ่ง
`npm run native:repair`จากเช็คเอาท์ นี้จะเรียกคืนแพกเกจเพิ่มเติม
ซ่อมแซมSQLiteสําหรับElectronเตรียมการNodeสําหรับการประมวลผลภาพแบบแยก
และเช็ค SQL, ตารางสี-เว็บ และคมชัดก่อนที่จะประสบความสําเร็จ
ใช้`npm run native:check`สําหรับเช็คโดยไม่มีการติดตั้ง
ดู[สคริปต์ตรวจสอบสิ่งเชื่อมโยง](./scripts/verify-native-dependencies.cjs)สําหรับการตรวจสอบ

Commander จัดการงานทั่วไปเองและผู้เชี่ยวชาญผู้แทนราษฎร ทํางานผ่านเครื่องมือ 3 อย่าง:

- **`dispatch_to`**ดําเนินการตัวแทนชื่อและผลตอบแทนสําหรับการทํางานอย่างต่อเนื่อง มันสามารถรอผลลัพธ์ หรือวิ่งอย่างไม่สิ้นสุดและแจ้งให้Commanderเมื่องานเสร็จสิ้น
- **`hand_off_to`**ย้ายงานที่เหลือไปยังตัวแทนชื่อและสิ้นสุดปัจจุบันCommanderเลี้ยว ตัวแทนที่ส่งมอบคําตอบของตัวเอง; การยืนยันทางเลือกปล่อยให้Commanderกลับไปทํางานที่กว้างกว่านี้หลังจากนั้น
- **`run_worker`**ดําเนินการไม่ระบุชื่อ, จําแนกงานย่อยและผลตอบแทนส่วนตัว มันไม่ได้ได้รับประวัติการสนทนา หรือทักษะของตัวแทน

และแรงงานนิรนาม มีการควบคุมความสอดคล้อง ดู[การจัดการการส่ง](./src/main/features/group_chat/bus.ts)ถึง[ล็อคการประมวลผล](./src/main/util/locks.ts).

### การจัดการคอนเท็กซ์

ดัชนีเวลาทํางาน ขัดแย้งกับความจุในการป้อนของรุ่นที่เลือกไว้ บัญชีเพื่อแจ้งเตือน เครื่องมือ และสถานะการทํางานอย่างต่อเนื่อง กล่องโต้ตอบที่เสร็จสมบูรณ์แล้วจะใช้หน้าต่างที่มีขอบและงานยาวที่ทํางานอยู่ ใช้จุดตรวจเพื่อรวมจดหมายที่ประมวลผลก่อนหน้า ในขณะที่ยังเก็บงานล่าสุดไว้ การอ่านแฟ้ม การเปลี่ยนแปลงของแฟ้ม และการประมวลผลคําสั่งยังมีโครง คุณสามารถช่วยวิกิพีเดียได้

ดู[ดัชนี](./src/core-agent/src/agent/context-budget.ts), [ประวัติและจุดตรวจของเซสชัน](./src/core-agent/src/agent/session.ts)ถึง[บันทึกขอบเขตสี](./src/core-agent/src/agent/workspace-state.ts).

### หน่วยความจําและไลบรารี

โน้ตที่ดูง่ายเก็บค่าผู้ใช้, ข้อเท็จจริงโครงการ และความรู้ของตัวแทนแต่ละตัว ในขอบเขตที่แยกกันอยู่ บันทึกเหล่านี้แตกต่างจากดัชนีเอกสารของห้องสมุด และประวัติการสนทนาที่เก็บไว้

ห้อง สมุด จะ สกัด เอกสาร ต่าง ๆ เข้า ไป ใน ทาง เดิน และ เก็บ เอกสาร ใน ท้อง ถิ่นSQLiteดัชนีเวกเตอร์ แบบจําลองการฝังตัวของมันทํางานบนเครื่องของคุณ;`library`เครื่องมือสามารถแสดงรายการแฟ้ม, สืบค้นเนื้อความที่เกี่ยวข้อง และอ่านเนื้อหาจากคลังสื่อทั่วไปหรือรายการปัจจุบัน การสนทนาก่อนหน้านี้ถูกรับแยกผ่านทาง`chat_history`.

ดู[หน่วยความจําที่ถูกสํารวจ](./src/main/features/memory.ts), [การดึงเอกสาร](./src/main/util/file_to_chunks.ts), [เครื่องมือไลบรารี](./src/main/model/core-agent/kb-tools.ts)ถึง[เริ่มการสนทนาได้](./src/main/model/core-agent/chat-history-tools.ts).

การล็อคกลุ่มงานและจํากัดความต่อเนื่องของงาน งบประมาณแบบพกพา, ด่านตรวจความคืบหน้า เช็คโทรซ้ํา และหน่วยเฝ้าระวังที่ไม่รู้ระยะ และความช่วยเหลือของสุนัขที่ไม่ได้ใช้ ประกอบด้วยการทํางานที่คอกหรือทําซ้ําการทํางาน คุณสามารถติดตามและยกเลิกงานของตัวแทนที่มีชื่อและทําต่อไปนี้ได้ แต่ทาสก์ที่ยอมรับแล้วหรือทําคิวไว้อาจจะยังไม่เป็นผลสําเร็จ

## ขนาด FAQ

**อะไรOrkas?**
Orkasเป็นโอเพนซอร์ส(MIT)แอพพลิเคชันเดสก์ทอปแบบหลายเอฟเฟ็คต์ มันCommanderเปลี่ยนเป้าหมายของคุณเป็น สิ่งที่จะทํา และพิกัด 16 บุคลากรผู้เชี่ยวชาญClaude Code, Codex, OpenCode, OpenClawถึงHermes-Agent-ส่งเอกสารเสร็จ ไม่มีแชทบอทเดียว, ไม่มีโครงสร้างรหัส, ไม่เป็นเจ้าภาพSaaS.

**ฉันต้องการAPIกุญแจ?**
ไม่ แอพแพกเกจมาพร้อมกับ 500 เครดิตสําหรับการสร้างภายในOrkasนางแบบ หลัง จาก นั้น ให้ ซื้อ บัตร เครดิต ให้ เลือก แผนการ จ่าย หรือ เพิ่ม กุญแจ ผู้ หา เลี้ยง ตัว เอง; ค่า ใช้ จ่าย ต่าง ๆ แยก กัน.

**คือOrkasภายในระบบLLM?**
ไม่Orkasทํางานในเครื่องของคุณ และเรียกแบบจําลองที่คุณเลือกOrkasนางแบบ ของคุณAPIกุญแจ หรือจุดปลายแบบท้องถิ่น มันสร้างตัวแทนและเครื่องมือ มันไม่ใช่แบบจําลอง

**ทําได้Orkasตอบคําถามจากเอกสารของฉันด้วยเครื่องหมาย?**
ใช่ เพิ่มเอกสารและเอกสารต่าง ๆ ไปยังไลบรารีของคุณOrkasสามารถค้นหาและตอบด้วยการอ้างอิงไปยังแหล่งย่อย ดังนั้นคุณสามารถเปิดต้นฉบับและตรวจสอบ ดัชนีถูกสร้างจากเครื่องของคุณ

**ฉันใช้นางแบบท้องถิ่นอย่างOllamaหรือLM Studio?**
ใช่ เปิด**ตั้งค่าบัญชีผู้ใช้ ○ รุ่นต่าง ๆ**เลือก**ใช้งาน OpenAI ได้**หรือ**ความเข้ากันได้ของมานุษยวิทยา**และป้อนที่อยู่ URL ฐาน ID รุ่นที่แน่นอน และAPIกุญแจ เลือกรุ่นที่บันทึกไว้จากรุ่นควบคุมงาน

**ที่เป็นของฉันAPIกุญแจและเก็บข้อมูล?**
บนดิสก์ของคุณโดยปริยาย กุญแจผู้ให้บริการของคุณเองมีการเข้ารหัสในท้องถิ่น และกันออกจากการปรับกลุ่มเมฆ ด้วยกุญแจของคุณเองโทรรุ่นไปตรงจากเครื่องของคุณไปยังผู้ให้บริการ; สร้างภายในOrkasรุ่นที่ใช้Orkasจัดการบริการ ปรับเทียบข้อมูลเมฆและแบ่งปันโครงการในโปรแกรมแพกเกจ เก็บข้อมูลที่เลือกไว้Orkasเซิฟเวอร์[การรักษาความปลอดภัยและการจัดการข้อมูล →](https://orkas.ai/security/?source=gh-orkas)

**ใช่Orkasงานออฟไลน์?**
การสร้างแหล่งที่มาสามารถทํางานได้อย่างสมบูรณ์กับจุดปลายแบบท้องถิ่น แอพแพกเกจต้องลงชื่อ และโมเดลเมฆต้องการการเชื่อมต่อ

**มันยังคงทํางานเมื่อคอมพิวเตอร์ของฉันปิด?**
ไม่Orkasทํางานบนคอมพิวเตอร์ของคุณดังนั้นอัตโนมัติและระบบอัตโนมัติต้องตื่นและOrkasวิ่ง จาก v1.9 แต่ละอัตโนมัติจับ พลาดล่าสุดทํางานภายใน 12 ชั่วโมงเมื่อคอมพิวเตอร์ตื่นหรือOrkasเริ่มได้

**ฉันสามารถสร้างและตีพิมพ์แอพ?**
ใช่ แอพพลิเคชันภายในOrkasเป็นอิสระ การลงเว็บแอปไปยังลิงก์สาธารณะต้องการแผนการจ่ายเงิน(Lite 5, Pro 8, Max 15 Apps)และตีพิมพ์เว็บแอพไม่ได้รวมทุกความสามารถภายในOrkas.

**ฉันต้องการOrkasบัญชี?**
โปรแกรมเดสก์ทอปที่บรรจุแพกเกจได้ขอให้คุณเซ็นมัน เมื่อคุณเริ่มทํางานครั้งแรก แหล่ง ที่ มา ของ ห้อง เก็บ ของ นี้ ไม่ มี ชั้น บัญชี เลย — มัน จะ ยัด เข้า ไป ใน แอพ ทันที.

**ทําได้Orkasไดรฟ์Claude Codeและอื่น ๆCLIเจ้าหน้าที่?**
ใช่Orkasขับข้างนอกได้ 5 คนCLIตัว แทน ใน ฐานะ ผู้ ดําเนิน การ ย่อย ใน ท้อง ถิ่น — ตัว แทน ที่ ใช้ รหัสClaude Code, CodexถึงOpenCodeรวมทั้งสายลับส่วนตัวOpenClawถึงHermes-Agent-และโครงการโอเพนซอร์สเช่นHyperFramesทั้งหมดกํากับจากการสนทนาเดียวกัน

**เป็นไงบ้างOrkasแตกต่างจากClaude Code / Codex / CrewAI / LangChain?**
Claude CodeถึงCodexเป็น ตัว แทน ใน การ เขียน รหัส —Orkasทํางานในทีมทั้งคู่ ดังนั้นคุณไม่จําเป็นต้องเลือกระหว่างพวกเขาCrewAIถึงLangChainเป็นรูปแบบแรกของรหัสOrkasเป็นโปรแกรมเดสก์ทอปแบบโอเพนซอร์สที่Commanderพิกัดทีมของเจ้าหน้าที่ผู้เชี่ยวชาญและของคุณCLIจนท. กับผู้จัดหาโมเดล และเก็บข้อมูลและกุญแจไว้ในท้องถิ่น ดู[การเปรียบเทียบเต็มรูปแบบ](https://orkas.ai/compare/?source=gh-orkas).

**เวทีไหนOrkasให้กําลังใจ?**
macOS 12+ (แอพเพล็ตและข้อมูล)ถึงWindows10+ มีการติดตั้งแพกเกจ glibc 2. 34+Linuxx64/Arm64 วิ่งหนีจากแหล่งที่มาวันนี้ โดยยังไม่มีผู้ติดตั้ง การแปลคําสั่งภาษาท้องถิ่นถูกรองรับLinuxผ่านการตรึงwhisper.cppเตรียมตัวทํางานก่อนเปิดตัวครั้งแรก ยังไม่รองรับการแจกจ่ายแบบมัลติมีเดียและมัลติมีเดียอื่น ๆ กับดักรองเท้าบูทNode 22.12+; Python3 และต้องการเครื่องมือก่อสร้าง C/C+ เฉพาะเมื่อแพกเกจ npm พื้นเมืองไม่มีที่เข้ากันได้ก่อนไบนารี และต้องสร้างขึ้นใหม่ภายในประเทศ

**คือOrkasฟรีและโอเพนซอร์ส?**
ใช่ แอพคือMITใบอนุญาตและใช้ฟรี App ที่บรรจุรวม 500 เครดิตสําหรับการสร้างภายในOrkasModel; จ่ายเงินแผนจาก $1.99/เดือน เพิ่มหน่วยกิตรายเดือน, การเทียบข้อมูลเมฆ, โครงการใช้ร่วมกันมากขึ้นและตีพิมพ์แอพ ด้วยกุญแจของคุณเอง การใช้โมเดลจะถูกเรียกเก็บเงินโดยผู้ให้บริการของคุณOrkasไม่เพิ่มเครื่องหมายบอกรับ[น้ํา หนัก ○](https://orkas.ai/pricing/?source=gh-orkas)
