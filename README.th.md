# Orkas

**ทีมงาน AI ที่เปิดแหล่งที่ใช้อยู่บนโต๊ะทํางานของคุณ มันเปลี่ยนเป้าหมายของคุณเป็นงานสําเร็จรูป และทําให้มันเคลื่อนไหว**

Orkas เป็นแอพพลิเคชั่นแบบเปิดแหล่ง (MIT) ที่ใช้งานในพื้นที่เป็นครั้งแรก**Commander** สิ่งที่คุณต้องการ: มันทําหน้าที่หลายอย่างเอง และสําหรับงานใหญ่ มันวางแผนขั้นตอนและนําตัวแทนเชี่ยวชาญ รวมไปถึงตัวแทนการเขียนโค้ดและตัวแทนส่วนตัวที่คุณใช้อยู่แล้ว**Claude Code, Codex, OpenCode, OpenClaw และเฮร์เมส-เอเจนต** งามนี้ร่วมกัน

Orkasถูกสร้างเพื่อให้โครงการเคลื่อนไหว ไม่ใช่แค่ตอบคําสั่งเดียว**โครงการ** จัดเป้าหมาย กติกา ความจํา และไฟล์ ดังนั้นทุกการพูดคุยใหม่ จะเริ่มต้นจากที่ที่จบ**ทํางาน** แบ่งงานระหว่างคนและเจ้าหน้าที่**Auto-advance** ให้ทีมรับมือกับงานต่อไปเอง**การอัตโนมัติตามกําหนด** ทํางานประจําเป็นชั่วโมง, ทุกวัน, ทุกสัปดาห์ หรือทุกเดือน ทุกข้อมูลของคุณจะอยู่ในคอมพิวเตอร์ และงานเสร็จกลับมาเพื่อการตรวจสอบของคุณ

### สร้างคลิปที่อ้างอิงด้วยเนื้อหาของคุณเอง

**VideoStudio** สามารถสร้างโครงสร้างการเล่าเรื่อง, สไตล์ภาพและความเร็วในการแก้ไขของวีดีโอไวรัสได้โดยใช้สินค้า, หมวดลายและวิดีโอของคุณเอง. ให้ไฟล์วีดีโออ้างอิงและทรัพย์สินของคุณ: เจ้าหน้าที่วิเคราะห์ hook, ระดับข้อมูล, การเต้นทาง بصرية และการเรียกการกระทํา, จากนั้นเสนอสิ่งที่ต้องรักษาและสิ่งที่ต้องเปลี่ยนก่อนผลิต

วิธีนี้ใช้ได้ดีที่สุดสําหรับผู้อธิบายภาพยนตร์, SaaS หรือการแสดงแอพ และโฆษณาสินค้าที่สร้างขึ้นจากวิดีโอที่มีอยู่ของคุณ. ข้อความ, คําบรรยาย, การเล่าและคลิปที่เขียนโดยผู้เขียนในพื้นที่สามารถแก้ไขได้แยกกัน; ข้อความที่เตาลงในวิดีโอที่เกิดจาก AI ต้องเปลี่ยนวิดีโอนั้น

> "ใช้ reference.mp4 เป็นอ้างอิงสําหรับโปรโมชั่น 30 วินาที ยืนยันไว้ว่ามันเป็นฮัก, การเขียนแบบและการเรียงความเร็ว, แทนเนื้อหาด้วยผลิตภัณฑ์ของฉัน และบันทึกจอ, และแสดงให้ฉันเห็นการแยกและแผนก่อน"

เริ่มจากไฟล์วีดีโอที่เจ้าหน้าที่สามารถอ่านได้; การดาวน์โหลดลิ้งส่วนร่วมในระบบโซเชียลพล็อตไม่ได้สร้างขึ้น. การเคลื่อนไหวของกล้องแม่นยํา, การแสดงของมนุษย์และการตรงกันแบบกรอบละกรอบไม่ได้รับประกัน[การทํางานระยะเวลาที่ระบุ](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

- **การทําหน้าที่และการอัตโนมัติ** — ✓ ทุกโครงการมีรายการของคนและเจ้าหน้าที่ที่จะทํา โดยกับ Auto-Advance เปิด, ทีมงานจะเก็บรายการต่อไปเองและนํางานเสร็จกลับมาเพื่อการรีวิวของคุณ
- **การอัตโนมัติตามกําหนด** — ครับ ครับ ครับ ทํางานทุกชั่วโมง ทุกวัน อาทิตย์ หรือเดือน Orkas ใช้งานบนคอมพิวเตอร์ของคุณ ตั้งแต่เวอร์ 1.9 ทุกระบบออโต้ตอบจะติดตามการทํางานที่พลาดล่าสุดภายใน 12 hours เมื่อคอมพิวເຕີตื่นขึ้นหรือ Orkas เริ่ม
- **เครื่องเชื่อมต่อ** — ✓ Gmail, Google Calendar, Sheets and Drive, Notion, Slack, Shopify, Stripe และอื่นๆ อีกมากมาย โดยปกติ Orkas ถามก่อนส่ง, โพสต์หรือลบอะไร
- **แอปต์** — ️อธิบายเครื่องมือ และ Orkas สร้างมันเป็นแอพท้องถิ่นภายในแอปตั๊ปโต๊ะทํางาน ในแอพพพัคเกจการจ่ายเงินยังสามารถตีพิมพ์มันเป็นแอพเว็บที่มีลิงค์สาธารณะ

## ทําไมออร์คา

- **Commanderที่วางแผน ส่งมอบหมาย และทําส่วนที่เหลือ** — ✓ มันแยกเป้าหมาย ออก เลือกตัวแทนที่เหมาะสม ความสามารถ คอนเนกเตอร์ และเครื่องมือ และจัดการวิเคราะห์ การเขียน การวิจัยและงานไฟล์เอง เมื่อไม่มีผู้เชี่ยวชาญ ที่เหมาะสมกว่า
- **ที่ตั้งแรกตามการออกแบบ** — ✓ การสนทนา, ไฟล์, แบสความรู้ และตัวแทนที่ใช้เองจะอยู่ในดิสค์ของคุณโดย मुलभूत. การสอดคล้องเมฆเป็นทางเลือกในแอพพพัคเกจ. ด้วยกุญแจของคุณเอง, การเรียกแบบจะไปตรงจากเครื่องของคุณไปยังผู้ให้บริการ; รุ่น Orkas แบบประกอบด้วยใช้งานผ่านบริการรุ่นจัดการของ Orkas.
- **ทุกรุ่นเปลี่ยนเวลา** — Commanderและเจ้าหน้าที่ในตัวแบ่งปันการตั้งแบบเดียวกัน: รูปแบบ Orkas ในตัว, ผู้ให้บริการของคุณเอง, หรือจุดปลายทางท้องถิ่น. เจ้าหน้าที่ CLI นอกรักษาการตั้งแบบของพวกเขาเอง.
- **เจ้าหน้าที่ที่ดีขึ้น** — ผู้นําแต่ละตัวถือรักษาความสามารถและความทรงจําส่วนตัว การตรวจสอบหลังวิจัยวิจัยการทํางานใหม่เมื่อแอพพนั้นว่าง และสามารถปรับปรุงการประเมินตนเอง, วิธีการใช้ได้อีกครั้งและทักษะที่เรียนรู้
- **แหล่งเปิด ไม่มีกล่องดํา** — อ่านสิทธิของออร์คาส และเจ้าหน้าที่และทักษะทุกคน

## เริ่มเร็ว

อยากได้เครื่องติดตั้งแบบพัคเกจแทนมั้ย[ดาวน์โหลด](#ดาวน์โหลด)ณ ปัจจุบันวิธีการทํางาน Orkas บน Linux:

**ความต้องการ**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 หรือ arm64. ทําให้ Python 3 และรุ่น C / C ++ สร้างทุลโซ่ให้ใช้สําหรับการสร้างหลุดหลุดแบบจํากัดที่ไม่ธรรมดา

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

การทํางานของแหล่ง Linux จําเป็นต้อง glibc 2.34+ แจ้ง Alpine และการกระจายที่ใช้งานบนมัสลอื่น ๆ ไม่สนับสนุน. การดาวน์โหลดคําแปลเสียงในท้องถิ่นและตรวจสอบเวลาทํางานและแบบหลายภาษาของเป้าหมาย whisper.cpp ในช่วงเปิดแหล่งแรก

`run.sh` / `run.cmd`ติดตั้งต้นไม้พึ่งพัง npm และเตรียม Python, uv, Node, รูปแบบการติดตั้ง (~95 MB), OfficeCLI, FFmpeg, whisper.cpp และทรัพยากรรรรแบบพูดหลายภาษาในการเปิดตัวครั้งแรก การเริ่มต้นของ Linux จากนั้นตรวจสอบโหลดพื้นที่และเวลาทํางาน Whisper ภายใต้ ABI ของ Electron ก่อนเปิดแอพลิเคชั่น`~/.orkas/`(macOS / Linux) หรือ`<smallest non-system drive>:\.orkas\`(Windows) แล้วเปิด**การตั้งค่า → ผู้ให้บริการ AI** เพิ่มเติมปุ่ม API หรือ OAuth

ความผิดพลาดการพึ่งพาพื้นเมือง: ใช้ Node.js 24 LTS (ขั้นต่ํา 22.12.0) แล้วใช้
`npm run native:repair`จากการตรวจสอบนี้ มันคืนแพ็คเกจที่เลือก
ซ่อม SQLite for Electron เตรียม Node ที่ถูกจับไว้เพื่อการแปรรูปภาพแบบแยกแยก
และตรวจสอบ SQL, sqlite-vec และคมชัดก่อนประสบความสําเร็จ
ใช้งาน`npm run native:check`สําหรับการตรวจสอบโดยไม่มีการติดตั้ง
ดู[สกรีนการตรวจสอบความพึ่งพาพื้นฐาน](./scripts/verify-native-dependencies.cjs)สําหรับการตรวจสอบที่ทํา

## วิธีการทํางาน

### การจัดทํางาน

Commanderจัดการงานทั่วไปเอง และมอบหมายให้ทํางานผู้เชี่ยวชาญผ่านเครื่องมือสามอย่าง

- **`dispatch_to`** — มันสามารถรอผลงานได้ หรือทํางานไม่สมอง และแจ้งCommanderเมื่อการทํางานเสร็จ
- **`hand_off_to`** — ส่งงานที่เหลือให้เจ้าหน้าที่ชื่อ และจบการทํางานของCommanderปัจจุบัน เจ้าหน้าที่จะตอบเอง การต่อเนื่องทางเลือกจะทําให้เจ้าหน้าที่บัญชาการสามารถดําเนินงานต่อไปในครั้งที่กว้างขวาง
- **`run_worker`** — ทํางานแบบไม่ทราบชื่อ และแยกตัว และคืนผลส่วนตัว มันไม่ได้รับประวัติการพูดคุย หรือความสามารถของเจ้าหน้าที่ที่ได้รับชื่อ

การทํางานของผู้แทนที่ชื่อและคนทํางานที่ไม่ทราบชื่อ มีการควบคุมเวลาเดียวกันแยก[การดําเนินการส่ง](./src/main/features/group_chat/bus.ts)และ[ปิดการประกอบ](./src/main/util/locks.ts).

### การจัดการสถานการณ์

การใช้เวลาในการทํางานของตารางการใช้งานที่ใช้งานกับความสามารถในการเข้าของแบบที่เลือก, การบัญชีสําหรับคําสั่ง, เครื่องมือและสถานการณ์การทํางานที่คงอยู่. การสื่อสารเสร็จสิ้นใช้หน้าต่างประวัติศาสตร์ล่าสุดที่จํากัด; งานที่ทํางานยาวนานใช้จุดตรวจสอบเพื่อประมวลสารกระบวนการก่อนหน้านี้โดยยังคงทํางานล่าสุด. การอ่านไฟล์, การเปลี่ยนแปลงไฟล์ และการดําเนินการบัญชาการยังมีบันทึกโครงสร้างที่สามารถรอดพ้นการคอมเพชิดในสภาพ

ดูสิ[งบประมาณในสภาพ](./src/core-agent/src/agent/context-budget.ts), [ประวัติการประชุมและจุดตรวจสอบ](./src/core-agent/src/agent/session.ts)และ[รายงานพื้นที่ทํางาน](./src/core-agent/src/agent/workspace-state.ts).

### ความ จํา และ ห้องสมุด

บันทึกที่มีความยั่งยืนเก็บความชอบของผู้ใช้, ข้อมูลโครงการและความรู้ที่สามารถนําไปใช้ได้อีกครั้งของตัวแทนแต่ละตัวในระยะที่แยกกัน. บันทึกเหล่านี้แตกต่างจากอัตราบันทึกเอกสารของห้องสมุดและประวัติการพูดคุยที่เก็บไว้

ห้องสมุดถอนเอกสารเป็นบทความ และเก็บอ индекс vector SQLite ของท้องถิ่น`library`เครื่องมือสามารถจัดรายการไฟล์ ค้นหาบทความที่เกี่ยวข้อง และอ่านเนื้อหาแหล่งจากห้องสมุดทั่วไปหรือโครงการปัจจุบัน`chat_history`.

ดูสิ[ความจําระยะ](./src/main/features/memory.ts), [การขอกสาร](./src/main/util/file_to_chunks.ts), [เครื่องมือห้องสมุด](./src/main/model/core-agent/kb-tools.ts)และ[การเรียกคืนการพูดคุย](./src/main/model/core-agent/chat-history-tools.ts).

### ขั้นต่ําการดําเนินงานและการเรียกคืน

การล็อคประชุมและจํากัดเวลาร่วมกันที่กําหนดการทํางานแบบตรงข้าม.งบประมาณรอบเครื่องมือ, จุดตรวจสอบความก้าวหน้า, ตรวจสอบการเรียกซ้ํา และผู้ดูแลฝ้าระยะที่รู้เกี่ยวกับระยะช่วยป้องกันการทํางานที่หยุดหรือซ้ํางาน.งานของตัวแทนชื่อสามารถติดตามและยกเลิกได้แต่ละคน; การรับผิดชอบหรือการทํางานในแถวไม่ได้ถูกพิจารณาเป็นผลสําเร็จ

## FAQ

**ออร์คาสคืออะไร?**
Orkas เป็นแอพพพลิเคชั่นแบบเปิดแหล่ง (MIT) ที่ใช้งานในพื้นที่เป็นครั้งแรกสําหรับหลายตัวแทน โดยCommanderของมันเปลี่ยนเป้าหมายของคุณเป็นการทํางาน และประสานงานกับ 16 ตัวแทนเชี่ยวชาญที่ติดตั้ง รวมถึง Claude Code, Codex, OpenCode, OpenClaw และ Hermes-Agent เพื่อส่งไฟล์เสร็จ

**ฉันต้องการกุญแจ API?**
ไม่ แอปพิกชั่นพร้อม 500 บาท สําหรับแบบ Orkas รวมแล้ว ซื้อ บาท ค่า สิ้น โปรแกรมเงิน หรือเพิ่มกุญแจผู้ให้บริการของคุณเอง

**ออร์คาสเป็นนักศึกษาที่ท้องถิ่นเหรอ?**
ไม่. Orkas ใช้เครื่องของคุณ และเรียกตัวอย่างที่คุณเลือก ครับ เป็นแบบ Orkas รุ่นยนต์, ปุ่ม API ของคุณเอง หรือจุดปลายของตัวอย่างในพื้นที่

**ออร์คาสสามารถตอบคําถามจากเอกสารของฉันได้ด้วยคําอ้างอิงหรือไม่**
ใช่. เพิ่มเติม PDF และเอกสารไปยังห้องสมุดในพื้นที่ของคุณ; Orkas สามารถค้นหาและตอบด้วยการอ้างอิงเพื่อแหล่งฉบับ, เพื่อให้คุณสามารถเปิดต้นฉบับและตรวจสอบ. อินเด็กซ์ถูกสร้างขึ้นบนเครื่องของคุณ.

**ฉันสามารถใช้ตัวอย่างในพื้นที่ เช่น โอลาม่า หรือ LM Studio ได้มั้ย**
ใช่ เปิด**การตั้งค่าบัญชี → แบบรูปแบบ → แชท → เพิ่มแบบรูปแบบ → ปรับแต่ง**, เลือก** สอดคล้องกับ OpenAI**หรือ** สอดคล้องกับมนุษย์**, และใส่ URL ฐาน, ID แบบแม่นยํา, และปุ่ม API. เลือกแบบที่บันทึกจากการควบคุมแบบของงาน

**เซ็นต์ API และข้อมูลของผมถูกเก็บไว้ที่ไหน**
ในดิสก์ของคุณโดย मुलभूत. คีย์ผู้ให้บริการของคุณเองถูกรหัสในพื้นที่และไม่เข้าร่วมสัญลักษณ์เมฆ. ด้วยคีย์ของคุณเอง, การเรียกแบบจะไปตรงจากเครื่องของคุณไปยังผู้ให้บริการ; รุ่น Orkas ที่สร้างขึ้นใช้บริการจัดการของ Orkas. การสัญลักษณะเมฆเป็นทางเลือก และโครงการแบ่งปันในแอพพพะเก็ตเก็บข้อมูลที่ได้รับเลือกบนเซอร์เวอร์ Orkas.[ความปลอดภัยและการจัดการข้อมูล](https://orkas.ai/security/?source=gh-orkas)

**ออร์คาสทํางาน offline?**
การสร้างแหล่งสามารถทํางานได้อย่างเต็มที่ offline กับจุดปลายของรุ่นในพื้นที่ แอพพิกซ์ต้องเข้าใช้งาน และรุ่นเมฆต้องการการเชื่อมต่อเครือข่าย

**มันยังทํางานได้มั้ย ตอนที่คอมพิวเตอร์ฉันปิด?**
ไม่ ️ Orkas ใช้ในคอมพิวเตอร์ของคุณ ดังนั้น Auto-Advance และอัตโนมัติต้องใช้คอมพิวເຕີตื่นและ Orkas ใช้งาน. จาก v1.9, การอัตโนมิตแต่ละจับการทํางานที่พลาดล่าสุดภายใน 12 hoursเมื่อคอมพิวตาร์ตหรือ Orkas ตื่น

**ฉันสามารถสร้างและตีพิมพ์แอปได้มั้ย**
ใช่ แอพลิเคชั่นในพื้นที่ที่ใช้งานภายใน Orkas เป็นฟรี การตีพิมพ์แอปพลิเคชันเว็บไปยังลิงค์สาธารณะต้องมีแผนการจ่ายเงิน (Lite 5, Pro 8, Max 15 แอปลิเคชัน) และแอปพลิเกชันเว็บที่ตีพิมพัยไม่ได้รวมถึงความสามารถทั้งหมดที่มีอยู่ใน Orkas

**ฉันต้องการบัญชีของออร์คาสไหม?**
แอพพเพคเกดเดสโต๊ปขอให้คุณเข้าใช้งานเมื่อคุณเปิดตัวครั้งแรก. แหล่งสร้างในสํานักเก็บข้อมูลนี้ไม่มีชั้นบัญชีเลย

**ออร์คาสสามารถdriveเคลื่อนคล๊อด โคด และเจ้าหน้าที่ CLI อีกคนได้มั้ย**
ใช่. Orkas สามารถdriveเคลื่อนตัวแทน CLI ภายนอกห้าตัวเป็นกระบวนการรองพื้นที่ หน่วยงานเขียนโค้ด Claude Code, Codex และ OpenCode รวมถึงตัวแทนส่วนตัว OpenClaw และ Hermes-Agent และโครงการเปิดแหล่ง เช่น HyperFrames ทั้งหมดถูกกํากับจากจอเดียวกัน

**ออร์กาสแตกต่างจากคล๊อด คอดีส / Codex / ครูเอไอ / แลงเชนอย่างไร**
โคลด์โค้ด และโค้ดคอ๊ดซ์ เป็นตัวแทนโครงการ หน่วยงานโครงการโครงการ Orkas ใช้งานทั้งคู่เป็นสมาชิกในทีมของตัวเอง ดังนั้นคุณจึงไม่จําเป็นต้องเลือกระหว่างพวกเขา CrewAI และ LangChain เป็นกรอบโครงการแรกโครงการ Orkas เป็นแอพพลิเคชั่นโต๊ปแบบเปิดแหล่งที่Commanderประสานงานทีมของตัวแทนเชี่ยวชาญและตัวแทน CLI ของคุณ, กับผู้ให้บริการแบบใด ๆ และเก็บข้อมูลและกุญแจอยู่ในพื้นที่[การเปรียบเทียบเต็ม](https://orkas.ai/compare/?source=gh-orkas).

**โปรแกรมไหนที่ออร์คาสสนับสนุน?**
macOS 12+ (Apple Silicon และ Intel) และ Windows 10+ มีตัวตั้งค่าพัคเกจ glibc 2.34+ Linux x64/arm64 ออกจากแหล่งในวันนี้ โดยไม่มีตัวตั้งค่าใด ๆ ยังคงมีการรับรองในการเขียนเสียงใน Linux ผ่านเวลาทํางานของ whisper.cpp ที่ถูกปิดไว้ที่เปิดตัวครั้งแรก การกระจาย Alpine และกระจายงานอื่นๆ مبتنیบน Musl ไม่สนับสนุน bootstrap แหล่งต้องการ Node 22.12+ Python 3 และเครื่องมือสร้าง C / C++ ต้องใช้ได้เพียงเมื่อ gói npm ของพื้นเมืองไม่มี binary prebuilt ที่เข้ากันและต้องสร้างใหม่ในพื้นที่
