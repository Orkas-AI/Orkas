# Orkas

**Команда агентов AI с открытым исходным кодом на вашем рабочем столе превращает ваши цели в законченную работу и поддерживает ее в движении.**

Orkas - это открытый исходный код (MIT), первое локальное многоагентское рабочее место**Commander** что вам нужно: он выполняет многие задачи самостоятельно, а для больших работ он планирует шаги и привлекает специализированных агентов вместе с кодированием и персональными агентами, которые вы уже используете**Claude Code, Codex, OpenCode, OpenClaw и Hermes-Agent** — работать над этим вместе.

Orkas создана для того, чтобы поддержать движение проекта, а не просто ответить на один запрос.**проект** Содержит цель, правила, память и файлы, так что каждый новый разговор начинается там, где остался последний.**До-до** разделить работу между людьми и агентами,**Auto-advance** позволяет команде самостоятельно взять на себя следующее задание, и**планируемые автоматизации** Все ваши данные остаются на вашем компьютере, и законченная работа возвращается для вашего обзора

## Продолжайте работать

Одно из задач - это хороший старт. Orkas построены для работы, которая продолжается.

- **Проекты** — цели и правила, память и файлы, с которых начинается каждый разговор в проекте, так что вы никогда не будете кратко рассказывать о начале.
- **До-до и Авто-аванс** — каждый проект имеет список задач для людей и агентов; с автопрогрессом команда сама по себе подбирает следующий пункт и возвращает законченную работу для вашего обзора.
- **Планируемые автоматизации** — Окаса работает на вашем компьютере. С версии 1.9, каждая автоматизация задерживает свой последний пропущенный запуск в течение 12 hours, когда компьютер проснется или Orkas запускается.
- **Сключатели** — Gmail, Google Calendar, Sheets and Drive, Notion, Slack, Shopify, Stripe и многое другое.
- **Приложения** — описывать инструмент и Orkas создает его как локальное приложение внутри настольного приложения. В упакованном приложении платные планы также могут публиковать его в качестве веб-приложения с общественной ссылкой.
- **Совместные проекты** — *(упаковано приложение)*пригласить товарища по команде или ВА, и дать каждое задание человеку или агенту.

## Почему орки

- **Commander, который планирует, делегирует и делает все остальное.** — он разлагает цели, выбирает подходящих агентов, навыков, соединителей и инструментов, и сам решает анализ, написание, исследования и работу с файлами, когда ни один специалист не подходит лучше.
- **Местный - первый по конструкции** — Разговоры, файлы, базы знаний и пользовательские агенты остаются на вашем диске по умолчанию. Синхронизация облака является опциональным в упакованном приложении. С помощью ваших собственных ключей модели звонков отправляются прямо с вашего компьютера к провайдеру; встроенная модель Orkas работает через управляемую модельную услугу Orkas.
- **Любая модель, перемены в любое время** — Commander и встроенные агенты разделяют одну модель: встроенную модель Orkas, собственного поставщика или локальный конечный пункт.
- **Агенты , которые улучшаются** — каждый агент сохраняет свои навыки и память.
- **Открытый код, нет черной коробки** — Прочитайте, что делают Orkas и все агенты и навыки.

## Быстрый старт

Хочешь вместо этого упакованную установку?[Скачать](#скачать)Для запуска из источника      в настоящее время способ запуска Orkas на Linux:

**Требования**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 или arm64. Держите Python 3 и цепочку инструментов по созданию C/C++ доступны для необычного восстановления создания исходных модулей.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

Linux требует glibc 2.34+. Alpine и другие дистрибутивы на основе муссов не поддерживаются.

`run.sh` / `run.cmd`загружает запертое дерево зависимости npm и готовит закрепленный Python, uv, Node, встроенный модель (~95 MB), OfficeCLI, FFmpeg, whisper.cpp и многоязычные ресурсы модели речи при первом запуске. Затем стартап Linux проверяет платформенные модули и время работы Whisper под ABI Electron перед открытием приложения.`~/.orkas/`(macOS / Linux) или`<smallest non-system drive>:\.orkas\`(Windows). Тогда откройте**Настройки → Провайдеры AI** Добавить API-ключ или OAuth.

Нейные ошибки зависимости: используйте Node.js 24 LTS (минимум 22.12.0), затем запустите
`npm run native:repair`Это восстанавливает дополнительные пакеты,
восстанавливает SQLite для Electron, готовит сгруппированный узл для изолированной обработки изображений,
и проверяет SQL, sqlite-vec и острый до успеха.
Использование`npm run native:check`для проверки без установки.
Смотрите[скрипт проверки зависимости на родине](./scripts/verify-native-dependencies.cjs)для проведенных проверок.

## Как это работает

### Направление задач

Commander сам занимается общей работой и делегирует специализированную работу через три инструмента:

- **`dispatch_to`** — Он может ждать результата или запускать его асинхронно и сообщать командующему, когда задача закончится.
- **`hand_off_to`** — передает оставшуюся работу назначенному агенту и заканчивает текущий поход командующего.
- **`run_worker`** — Он выполняет анонимную и изолированную задачу, и возвращает частный результат.

Назначенные задачи агента и анонимные работники имеют отдельные контрольные системы одновременного управления.[реализация отправки](./src/main/features/group_chat/bus.ts)и[замок исполнения](./src/main/util/locks.ts).

### Управление контекстом

Контекст бюджетного времени запуска в сравнении с использоваемой возможностью ввода выбранной модели, учетом запросов, инструментов и постоянного состояния времени запуска. Завершенный диалог использует ограниченное окно недавней истории; длинные активные задачи используют контрольные точки для конденсации более ранних сообщений процесса при сохранении недавней работы. Читание файлов, изменения файлов и выполнение команд также имеют структурированные записи, которые могут пережить сжатие контекста.

Посмотрите[контекстные бюджеты](./src/core-agent/src/agent/context-budget.ts), [история сеанса и пункты пропуска](./src/core-agent/src/agent/session.ts)и[записи рабочего пространства](./src/core-agent/src/agent/workspace-state.ts).

### Память и библиотека

Прочные записки хранят предпочтения пользователей, факты проекта и многократные знания каждого агента в отдельных объемах.

Библиотека извлекает документы в отрывки и хранит локальный векторный индекс SQLite.`library`инструмент может перечислить файлы, искать соответствующие отрывки и читать исходный контент из глобальной или текущей библиотеки проекта.`chat_history`.

Посмотрите[охватная память](./src/main/features/memory.ts), [извлечение документов](./src/main/util/file_to_chunks.ts), [Библиотечные инструменты](./src/main/model/core-agent/kb-tools.ts)и[восстановление разговора](./src/main/model/core-agent/chat-history-tools.ts).

### Лимиты исполнения и возмещение

Замок сессии и ограничения совпадения, связанные с параллельной работой. Бюджеты инструмента, контрольные пункты прогресса, проверки повторных вызовов и фазосознательные безработные наблюдатели помогают удержать запуска, которые задерживают или повторяют работу.

Посмотрите[бюджеты актеров](./src/main/features/group_chat/actor-budgets.ts),[время работы агента](./src/core-agent/src/agent/runner.ts)и[адаптер настольной модели](./src/main/model/core-agent/client.ts).

### Учение от деятельности

В основе отзывов рассматривается новая деятельность агента, когда приложение не работает, с учетом отключений и ограничений исполнения.`COMPETENCE.md`), методы повторного использования (`LEARNING_STRATEGIES.md`Оценки зависят от новой деятельности, а не от количества задач, и могут привести к выводу, что ничего не стоит сэкономить.

Смотрите[график отражения](./src/main/features/reflection-orchestrator.ts)и[проспект обзора](./src/core-agent/src/evolution/metacognition.ts).

## Часто задаваемые вопросы

**Что такое Орка?**
Orkas - это открытодоступное приложение для настольных компьютеров с первым локальным многоагентом.

**Мне нужен ключ API?**
Нет. упакованное приложение поставляется с 500 кредитами для встроенной модели Orkas. После этого, купите кредиты, выберите платный план или добавьте собственные ключи провайдера; расходы провайдера отдельны.

**Orkas - местный магистр?**
Нет. Orkas работает на вашем компьютере и называет выбранные вами модели встроенной моделью Orkas, собственными API-ключами или локальным конечным пунктом модели.

**Orkas могут ответить на вопросы из моих документов с цитатами?**
Да. Добавьте PDF-файлы и документы в местную библиотеку; Orkas может искать их и отвечать с цитатами на исходные отрывки, чтобы вы могли открыть оригинал и проверить.

**Могу ли я использовать местные модели, такие как Оллама или LM Studio?**
Да, открытый.**Настройки учетной записи → Модели → Чат → Добавить модель → Устройство**, выбирать** Совместимость с OpenAI**или** Антропо-совместимый**, и введите базовый URL, точный идентификатор модели и ключ API. Выберите сохраненную модель из управления модели задачи.

**Где хранятся мои API-ключи и данные?**
На вашем диске по умолчанию. Ключи вашего собственного поставщика шифруются локально и исключаются из синхронизации в облаке. С помощью ваших собственных ключей модели звонков отправляются прямо с вашей машины к поставщику; встроенная модель Orkas использует управляемую услугу Orkas.[Безопасность и обработка данных →](https://orkas.ai/security/?source=gh-orkas)

**Orkas работают вне сети?**
Источник может работать полностью вне сети на локальном конечном пункте модели.

**Он работает, когда мой компьютер выключен?**
От версии 1.9 каждая автоматика задерживает свой последний пропущенный ход в течение 12 hours, когда компьютер просыпается или Orkas запускается.

**Могу ли я создавать и публиковать приложения?**
Да. Местные приложения, работающие внутри Orkas бесплатны. Публикация веб-приложения на публичную ссылку требует платного плана (Lite 5, Pro 8, Max 15 приложения), а опубликованные веб-приложения не включают все возможности, доступные внутри Orkas.

**Мне нужен счет Orkas?**
В упакованном настольном приложении просит вас войти в систему, когда вы запустите его впервые.

**Orkas могут водить Клода Кода и других агентов СИЗ?**
Да. Orkas может управлять пятью внешними агентами CLI в качестве местных подпроцессов ‒ агентами кодирования Claude Code, Codex и OpenCode, плюс персональными агентами OpenClaw и Hermes-Agent ‒ и на борту проектов с открытым исходным кодом, таких как HyperFrames, все направленные из одного чата.

**Чем Orkas отличается от Claude Code / Codex / CrewAI / LangChain?**
Claude Code и Codex - это агенты кодирования      Orkas работает как в качестве членов своей команды, поэтому вам не нужно выбирать между ними; CrewAI и LangChain являются рамками для кода первых. Orkas - это открыто-источник настольное приложение, где командир координирует команду специализированных агентов и ваших агентов CLI с любым поставщиком моделей, и хранит данные и ключи локально.[полные сравнения](https://orkas.ai/compare/?source=gh-orkas).

**Какие платформы поддерживают Орка?**
macOS 12+ (Apple Silicon и Intel) и Windows 10+ имеют упакованные установки. glibc 2.34+ Linux x64/arm64 работает из источника сегодня, без установки пока. Локальная транскрипция речи поддерживается на Linux через запчатанный шприц.cpp время запуска, подготовленное при первом запуске. Alpine и другие дистрибутивы на основе musl не поддерживаются. Источник bootstrap нуждается в Node 22.12 +; Python 3 и инструмент построения C / C ++ необходимы только тогда, когда у npm-пакета нет совместимого предварительно созданного бинарного и необходимо перестроить его локально.

**Orkas свободный и открытый?**
Да — приложение лицензировано MIT и бесплатное для использования. Обусловленное приложение включает в себя 500 credits для встроенной модели Orkas; платные планы от $ 11,99 / месяц добавляют ежемесячные кредиты, облачная синхронизация, больше совместных проектов и публикация приложений. С вашими собственными ключами использование модели зачисляется вашим провайдером; Orkas не добавляет маркировку.[Цены →](https://orkas.ai/pricing/?source=gh-orkas)
